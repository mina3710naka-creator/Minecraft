# 最強のブーツ (OP Boots) — Minecraft データパック

装備するだけで**耐性強化常時（全ダメージ無効）・不可壊・跳躍力強化・移動速度アップ**になり、
**Shift+ジャンプで真上に10マスジャンプ**、**Shiftを3秒長押ししてからジャンプで爆発を伴う10マスジャンプ**、
さらに**空中でシフトを押すと1回だけ空中ジャンプ**できる「最強のブーツ」を追加するデータパックです。
すべて `function`（コマンド）で実装しています。
10マスジャンプ・空中ジャンプはどちらも `tp` を使わず、**足元に一旦静止させたウィンドチャージを、
Motionを書き換えて地面へ叩き込んで起爆させ**、その爆風の上向きノックバックだけで真上に打ち上げます。

対応バージョン: **Minecraft Java Edition 26.2**（データパック形式 **107** / `min_format` `max_format` 方式）

---

## 効果一覧

| 効果 | 内容 |
| --- | --- |
| 耐性 Lv.11（常時） | ダメージを100%軽減。さらに毎tick体力を監視し、万一減っていたら即座に全回復させることで、奈落や `/kill` のような耐性で防ぎきれない特殊なダメージも実質無効化 |
| 炎耐性（常時） | 炎・溶岩ダメージを無効化 |
| 跳躍力強化 Lv.5（常時） | 通常のジャンプが高くなる |
| 移動速度上昇 Lv.16（常時） | 歩行速度が大幅に上がる |
| 不可壊 | ブーツの耐久値が減らない |
| Shift + ジャンプ | その場から真上に約10マスジャンプ（`tp` は使わず、足元のウィンドチャージを地面に叩き込んで起爆した爆風のみ） |
| Shiftを3秒長押し + ジャンプ | 爆発の演出とともに周囲を吹き飛ばしつつ、同じ10マスジャンプを発動（本人はブーツの効果で無傷、ブロックは壊さない） |
| 空中でシフト | 地面に足がついていない間に1回だけ、その場からさらに10マスジャンプ（着地するとまた1回使えるようになる） |

## 導入方法

1. このリポジトリの `opboots` フォルダを、ワールドの `datapacks` フォルダにコピーします。

   ```
   .minecraft/saves/<ワールド名>/datapacks/opboots/
   ├── pack.mcmeta
   └── data/
   ```

2. ワールドに入って `/reload` を実行します。
   チャットに `[最強のブーツ] 読み込み完了` と表示されれば成功です。

3. アイテムを受け取ります。

   ```
   /function opboots:give
   ```

4. 受け取った「最強のブーツ」をブーツ枠に装備します。

   * **Shift（スニーク）を押しながらジャンプ** → 真上に10マスジャンプ
   * **Shiftを3秒押し続けてからジャンプ** → 爆発演出付きの10マスジャンプ
   * **空中でシフトを押す** → 着地するまでに1回だけ空中ジャンプ

### アンインストール

```
/function opboots:uninstall
```
を実行してから、データパックのフォルダを削除してください。

## 調整できる数値

| 内容 | ファイル | 該当箇所 |
| --- | --- | --- |
| 耐性・跳躍強化・速度・炎耐性の強さ | `function/effects.mcfunction` | `effect give` 各行のamplifier（例：`minecraft:speed 1 15 true` の `15` が移動速度上昇Lv.16） |
| 溜め時間（3秒） | `function/jump/detect.mcfunction` | `ob.sneak matches 60..`（60tick=3秒） |
| ジャンプの高さ | `function/jump/leap.mcfunction` | `summon minecraft:wind_charge ...` の行数（＝足元に置くウィンドチャージの個数）。増やすほど爆風が強くなり高く飛ぶ。現在は1個でおおよそ10マス相当 |
| 多重発動を防ぐクールダウン・後始末タイミング | `function/jump/tick.mcfunction` | `ob.leapt matches 6..`（6tick=0.3秒。シフト押しっぱなしで連続ジャンプしないための待ち時間。この間毎tick残存ウィンドチャージのkillも試みる） |
| 爆発で吹き飛ばす範囲・威力 | `function/jump/explosive.mcfunction` | `damage @e[type=!player,distance=..4] 4 minecraft:explosion at ~ ~ ~` の `distance` と威力の値 |
| 装備判定に使うアイテム | `function/give.mcfunction` | ベースアイテム（`minecraft:netherite_boots`）と `minecraft:custom_data={opboots:1b}` |
| 対応バージョン範囲 | `pack.mcmeta` | `min_format` / `max_format`（26.2 = 107） |

## 実装メモ

* **装備判定** — `execute if items entity @s armor.feet *[minecraft:custom_data~{opboots:1b}]` で、
  ブーツ枠のアイテムに `custom_data` コンポーネント `{opboots:1b}` が付いているかを毎tick判定し、
  該当プレイヤーに `ob.wearing` タグを付ける。以降の効果・ジャンプ判定はこのタグを持つプレイヤーのみ処理する。
* **「全ダメージ無効」の実現方法** — 耐性Ⅴ（amplifier 4）はダメージを100%軽減できるが、
  奈落（`out_of_world`）や `/kill` など、一部のダメージ種別はポーション効果による軽減の対象外（bypass）になっている。
  これらも含めて確実に無効化するため、`scoreboard objectives add ob.hp health` で体力をそのまま反映するスコアを作り、
  毎tick「満タン（20）でなければ `minecraft:instant_health` で即全回復」という保険をかけている
  （`function/heal_check.mcfunction`）。耐性・炎耐性で防げるダメージは体力がそもそも減らないため発動せず、
  すり抜けたダメージだけをその場で打ち消す仕組み。
* **ジャンプ検知** — 統計 `minecraft.custom:minecraft.jump`（＝バニラの「ジャンプ」統計）を
  スコアボード条件でそのまま使い、値が増えた＝ジャンプした瞬間として検知したのち、
  毎tick末尾で `0` にリセットしている（フックショットの `hs.use` と同じ考え方）。
* **シフト判定** — プレイヤーのNBTは `/data` コマンドで読み書きできないため、
  `minecraft:entity_properties` 述語（`flags.is_sneaking`）でスニーク状態を判定している（`predicate/sneaking.json`）。
* **10マスジャンプの上昇方法（`tp` を使わない理由）** — `tp` でプレイヤーを直接動かす方式は、
  フックショットの README にもある通りクライアント側の予測処理とぶつかってカクついて見える上、
  当たり判定や向きの計算も必要になる。そこで `function/jump/leap.mcfunction` では、
  まず実行者（プレイヤー）自身の当たり判定に重なる位置にウィンドチャージを1個
  （`summon minecraft:wind_charge ~ ~0.1 ~ {NoGravity:1b,...}`）置き、その直後に
  `data modify entity <対象> Motion set value [0.0,-1.0,0.0]` でそのウィンドチャージの
  移動速度を書き換えて真下へ動かしている。ウィンドチャージは自分自身がブロックや
  エンティティに衝突すると爆発する仕様なので、すでに重なっているプレイヤー自身に
  ほぼ即座に衝突し、その場で確実に爆風を起こす。バニラの物理演算にそのまま任せているので
  `tp` は一切使っていない（現在の1個でおおよそ10マス相当）。
  * 最初は「矢を撃ち込んで起爆させる」方式を試したが、バニラの仕様上**矢は他の投射物
    （ウィンドチャージ自身も含む）には命中判定されない**ため起爆しなかった
    （矢が命中するのはボート・額縁・防具立てなど「拾える・持ち帰れる」扱いの実体のみ）。
    次に「足元の少し下（`~ ~-0.3 ~`）に置いて地面へ叩き込む」方式を試したが、これは
    **地面（ブロック）に衝突させることが前提**になるため、地面が近くにない空中ジャンプでは
    ウィンドチャージがそのまま落ち続けてプレイヤーから離れた場所でしか爆発せず、
    打ち上げ効果を得られなかった。そのため、地面の有無に関係なく常に確実に当たる
    **プレイヤー自身の当たり判定**にぶつける現在の方式に変更している（地上でも空中でも
    同じように動作する）。
  * `summon` した瞬間からいきなり下向きの初速を持たせても良いが、ここでは
    「まず自分の体に重ねて置く → 直後にMotionを書き換えて衝突させる」という2段階の処理にして、
    位置決めと起爆のタイミングを分けている。
  * バニラの物理演算に任せているため、正確に10.0マスになるとは限らない（フックショットの
    打ち上げ演出と同様、目安の値）。もっと高くしたい場合は上の表の通り `summon` の行を
    増やす（＝置くウィンドチャージの数を増やす）。
  * `function/jump/tick.mcfunction` は、何らかの理由で起爆せずに残ってしまったウィンドチャージの
    後始末（`kill @e[type=wind_charge,tag=ob.wc,distance=..4]`）に加え、シフトを押しっぱなしに
    したときに同じジャンプが連続発動しないよう、投げた直後の6tick（0.3秒）だけ
    `ob.leaping` タグを残しておくクールダウン管理も兼ねている。
* **常時効果を1秒にしている理由** — `effect give` は毎tick呼び出しているので、本来は
  1回だけ非常に長い時間（例：1000000秒）を指定しても見た目上は「常時」になる。しかし
  それだとブーツを脱いだ瞬間にも効果がしばらく残ってしまう上、ステータス画面に不自然に
  長い残り時間が表示され続ける。そこで効果時間をあえて1秒（20tick）という短い値にし、
  装備している間だけ毎tickかけ直し続けることで「装備中だけ確実に効果が乗っていて、
  脱いだら1秒以内に切れる」という常時効果を実現している。
* **空中ジャンプとその制約** — バニラの仕様上、ジャンプキー（スペースキー）の入力は
  すでに空中にいる間はそもそも判定されず、統計 `minecraft.custom:minecraft.jump` も
  増加しない（＝コマンドから「空中でジャンプキーが押された」ことを検知する方法がない）。
  そのため空中ジャンプは、代わりにいつでも検知できる**シフトキーの押下**を合図にしている。
  * 接地しているかどうかは、`execute unless block ~ ~-1 ~ #minecraft:replaceable` で
    足元のブロックが `#minecraft:replaceable`（空気や草など、乗ってもすり抜けるような
    ブロック）でなければ「接地」とみなす簡易判定を毎tick行っている（`ground_track.mcfunction`）。
    真のオンラウンド判定ではないため、階段やハーフブロックの端などではわずかにずれる場合がある。
  * `ob.sneak` は毎tickスニーク中に加算されるカウンターなので、値がちょうど`1`になった
    tick＝「シフトを押し始めた瞬間」として空中ジャンプの入力として扱っている
    （押しっぱなしで連続発動しないようにするため）。
  * 空中ジャンプは接地してから1回だけ使用可能（`ob.airjumped` タグで管理し、接地した
    瞬間にリセットされる）。通常の10マスジャンプ（`jump/leap.mcfunction`）をそのまま
    呼び出しているので、高さの調整方法も共通。
* **爆発ジャンプ** — 実際にブロックを破壊する爆発は使わず、`damage @e[...] ... minecraft:explosion at ~ ~ ~`
  （フックショットの打ち上げと同じ「着弾を伴わない爆発扱いのダメージ」コマンド）で周囲のモンスターなどに
  ノックバックとダメージだけを与え、演出として `explosion_emitter` / `explosion` パーティクルと爆発音を鳴らしたのち、
  通常の10マスジャンプ処理をそのまま呼び出している。本人はブーツの耐性・保険により無傷。

## ファイル構成

```
opboots/
├── pack.mcmeta
└── data/
    ├── minecraft/tags/function/   … tick / load への登録
    └── opboots/
        ├── predicate/sneaking.json   … スニーク判定
        └── function/
            ├── load / tick                … 初期化・毎tick処理
            ├── effects / heal_check       … 常時効果・被ダメージ無効化の保険
            ├── sneak_track                … シフト保持時間の計測
            ├── ground_track               … 接地判定・空中ジャンプ使用済みフラグの管理
            ├── give / uninstall
            └── jump/   … ジャンプ検知・通常/爆発/空中ジャンプ・後始末
```
