# 付与MOD (effectmod)

**付与台**で、剣・防具・ツールなど(スタックしないアイテム)に **効果** を付ける Minecraft(Fabric)用 MOD です。
効果は**文章で書いて**付けられるので、ボタンにない新しい効果も自分で作れます。

## 使い方
1. クラフト: 黒曜石×5 / エンチャントテーブル×1 / アメジストの欠片×2 / ブレイズパウダー×1
   ```
   アメジスト ブレイズ アメジスト
   黒曜石   エンチャントT 黒曜石
   黒曜石   黒曜石      黒曜石
   ```
2. 付与台を右クリックして、左上のスロットに効果を付けたいアイテムを入れる。
3. 右側のボタン(よく使う効果)を押すか、下の欄に**文章**を書く。「解釈:」に読み取った内容と必要レベルが出る。
4. 「付与」を押す。経験値レベルを消費する(クリエイティブは無料)。1つのアイテムに **3個まで**。「全削除」で消せる。

## 文章の書き方
「**いつ**」+「**何が起きる**」+(数字) をつなげて書くだけです。

| 例 | 結果 |
|---|---|
| `攻撃したとき雷を落とす 3` | 殴った相手に雷(威力3) |
| `右クリックで斬撃を飛ばす 4` | 前方に飛ぶ斬撃 |
| `歩くと足元に氷ブロックを置く` | 歩く先に氷の橋ができて、数秒で消える |
| `攻撃したとき相手の足元にクモの巣を置く` | 相手を拘束 |
| `30%の確率で相手に毒 8秒 2` | 確率つきのポーション効果 |
| `ダメージを受けたとき衝撃波 2` | 被弾で周囲を吹き飛ばす |
| `装備している間 速度 2` | 装備中ずっと移動速度アップ |
| `When hit, place ice under feet` | 英語・`minecraft:obsidian` のようなIDも可 |

### いつ(きっかけ)
| きっかけ | キーワード例 |
|---|---|
| 攻撃したとき | 攻撃 / 殴 / 当て / hit / attack |
| ダメージを受けたとき | 受け / され / 被弾 / hurt |
| 右クリックしたとき | 右クリック / 使 / use / click |
| 倒したとき | 倒 / キル / kill |
| ブロックを壊したとき | 掘 / 壊 / 破壊 / mine / break |
| 動いている間 | 歩 / 走 / 移動 / walk / run |
| 装備している間 | 装備 / 持って / いる間 / 常に |

きっかけを書かないと、ブロック設置は「動いている間」、ポーション効果(良いもの)は「装備している間」、それ以外は「右クリック」になります。防具に付けた効果は、持っていても着ていても発動します(攻撃・右クリック・破壊・倒したときは、手に持っているものだけ)。

### 何が起きる(効果)
| 効果 | キーワード例 | 備考 |
|---|---|---|
| 斬撃 | 斬 / slash | 前方に飛ぶ(威力で長さ・ダメージ) |
| 衝撃波 | 衝撃波 / 衝撃 | 周囲にダメージ+吹き飛ばし |
| 爆発 | 爆発 | 相手/視線の先。**ブロックは壊さない** |
| 落雷 | 雷 / 稲妻 | 見た目だけの雷+ダメージ。**火事・自爆なし** |
| 発火 / 凍結 | 燃 炎 火 / 凍 氷結 | |
| 火球 | 火球 / ファイアボール | 威力で数が増える |
| 回復 / 吸血 | 回復 ヒール / 吸血 吸収 | |
| ダッシュ / 大ジャンプ | ダッシュ 突進 / ジャンプ 跳 | |
| テレポート | テレポ 瞬間移動 ワープ | 視線の先へ(壁は越えない) |
| 吹き飛ばし | 吹き飛 ノックバック | |
| ブロック設置 | 置 設置 足場 橋 壁 / ブロック名 | 下記 |
| ポーション効果 | 毒 速度 再生 暗視 跳躍強化 …/ `poison` など英語ID | 悪い効果は相手、良い効果は自分(`自分` `相手` で指定可) |

**ブロック設置**: ブロック名は日本語(氷・石・黒曜石・ガラス・クモの巣…)、英語(`ice`)、ID(`minecraft:stone`)で書けます。
場所は `足元`(既定) / `相手の足元` / `周囲` / `壁` / `前` で指定。歩きながら・相手の足元・壁・周囲に置いたものは**数秒で消えます**(`永久` と書くと残る)。
チェストなどブロックエンティティ・岩盤・コマンドブロックなどは置けません。

### 数字
- `3` や `Lv3` … 威力(1〜10)。ポーションは強さ。
- `8秒` … 持続時間。
- `30%` … 発動確率。

## 作りと注意
- アイテムの効果は**アイテム自身のデータ**として保存されるので、ドロップ・チェスト・サーバー再起動をまたいで残ります(`effectmod:effects`)。
- 効果の発動はすべてサーバー側。マルチでも動く。クライアントにも MOD が必要(付与台の画面と説明表示のため)。
- 時間で消えるブロックの予約はメモリ上なので、**サーバーが止まると消えずに残ります**。
- 効果の解釈は `Parser.java` のキーワード表、中身は `Runner.java`。新しい効果の種類やキーワードを増やすならここに追加します。
- 動作確認: パーサー(全プリセット+例文)と、サーバー上での各効果の発動(斬撃・雷・爆発・発火・凍結・毒・吹き飛ばし・吸血・クモの巣・衝撃波・火球・ダッシュ・ジャンプ・テレポート・壁・前に置く・氷の橋と消滅・装備中ポーション)を確認済み。**付与台の画面(GUI)はビルドのみで、実機での見た目は未確認**です。

## ビルド
`.github/workflows/build-effectmod.yml`(Actions で Run workflow すると `effectmod/dist/` に jar を保存)。
ローカルでは JDK 25 + Gradle 9.5 で `gradle build`(`build/libs/effectmod-1.0.0.jar`)。
テクスチャは `python3 tools/gen_textures.py` で作り直せます。
