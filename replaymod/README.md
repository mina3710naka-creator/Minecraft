# povreplay(POV Replay)

Minecraft(Fabric)用の、クライアント専用 MOD。**リプレイ方式**の録画: プレイ中は、ゲームの通信とプレイヤー視点の状態を**記録するだけ**(とても軽い)。止めたあと、ワールドを出ると、記録を**再生し直して、高画質の動画(音つき)にする**。視点は、プレイヤー視点だけ。

(画面をそのまま動画にする MOD は `../recmod`。この MOD と同時には入れない — メニューのボタンが重なる。)

## 使い方

1. ワールドに入って、Esc でメニューを開く。左上に **「● 録画」** ボタンと **「録画一覧 (n/10)」** ボタンがある。「● 録画」を押すと録画を始める。
2. 録画中は、画面の左上に「● REC 0:12」が出る(動画には映らない)。もう一度 Esc → **「■ 停止」**。止めると、録画が**保存される**(最大 **10 件**まで。いっぱいのときは、録画を始められない)。
3. **「録画一覧」**(メニューにも、タイトル画面にもある)で、保存してある録画を、**いつでも、動画に書き出せる**。
   - 一覧の「書き出し」を押すと、ワールドを再生し直して、動画にする(ワールドの中で押したときは、ワールドを出てから始まる)。書き出した録画は、**「削除」するまで残る**(何度でも書き出せる)。いらない録画は、「削除」(2 回押す)で、ファイルごと消える。
   - 動画にしている間は、ワールドを再生し直している画面が出る。進み具合と、3 つのボタンがある:
     - **最小化**(右上の「－」でも): 進み具合と「拡大」のボタンだけを、画面の右上に残す。「拡大」(または Esc)で、元の大きさに戻る。
     - **プレビュー: 入/切**: 再生しているワールドを、背景に見せるか(切にすると、背景が真っ黒になる)。
     - **中止**: 書き出しをやめる(録画は、一覧に残る)。
   - 動画への圧縮は、ワールドを再生しながら、その場で行う(圧縮していない絵を、ディスクに溜めない。長い録画でも、ディスクを使いきらない)。終わると、タイトル画面に戻り、画面の隅に通知が出る。
4. **保存先**: ユーザーフォルダーの `Downloads` フォルダー(Windows なら `C:\Users\(ユーザー名)\Downloads`)。なければ、ゲームのフォルダーの `recordings/`。ファイル名: `minecraft-日時.mp4`。
   - 書き出している間は、**画面の右上**に「動画を保存中 72%」と進み具合を出し続ける(ワールドの中でも、タイトル画面でも)。終わると、保存した場所を 15 秒ほど出す。
   - 書き込み中のファイルは、`.mp4.part` という名前で、終わってから `.mp4` になる(途中でゲームが終わっても、壊れた動画は残らない)。
5. 録画は、ゲームを閉じても消えない(保存してある録画は、次に起動したときも、一覧に出る)。

## しくみ

- **プレイ中**(軽い): サーバーからゲームに届いた通信を、そのままの形で、時刻をつけて、ファイル(`povreplay/sessions/`)に書く(圧縮も、優先度の低い別のスレッドでする)。録画中は、描画のたびに、プレイヤー視点の状態(カメラの位置と向き・視野角・手の動き・歩くときの揺れなど。1 回 約 150 バイト)も書く。音は、聞こえたとおりに混ぜて、圧縮せずに、ファイルに書く。画面の絵は、取らない。
- **動画にするとき**: 本物のサーバーの代わりに、記録した通信を、偽の接続からゲームに流し込んで、ワールドを組み立て直す(シングルプレイでもマルチプレイでも同じ)。ゲームの時計を、1 フレームごとに 1/30 秒だけ進む仮想の時計にして、1 フレームずつ描き、絵を取る。絵を取り終わるまで時計を進めないので、重い場面でも、絵は飛ばず、いつも 30fps になる。視点と手の動きは、記録した値で上書きする。
- ウィンドウの大きさに関係なく、設定した大きさ(標準 1920x1080)で描き直すので、画面を小さくして遊んでいても、フルサイズの動画になる。

## ファイルを小さくする(ffmpeg)

**ffmpeg を入れておくと、動画のファイルが、同じ画質で 1/5〜1/8 ほど小さくなる**(内蔵のエンコーダーより、圧縮がずっと上手なため)。ffmpeg がなくても、内蔵のエンコーダーで書き出せるが、ファイルは大きくなる(1 分あたり 1GB 前後)。

- **入れ方**(ffmpeg に、libx264 が入っているもの。ふつうの配布版は、入っている):
  - Windows: コマンドプロンプトで `winget install Gyan.FFmpeg`(または、https://www.gyan.dev/ffmpeg/builds/ からダウンロードして、`C:\ffmpeg\bin\ffmpeg.exe` に置く)
  - Mac: `brew install ffmpeg`
  - Linux: `sudo apt install ffmpeg`(など)
- 入れたら、**設定は要らない**。MOD が、PATH や、よくある場所(`C:\ffmpeg\bin`、WinGet、Homebrew など)と、ゲームのフォルダーの `povreplay/ffmpeg(.exe)` から、自動で探す。見つかると、書き出しの画面に「(ffmpeg)」と出る。見つからないときは、画面の隅に通知が出て、内蔵のエンコーダーで書き出す。
- 画質は、`crf`(小さいほどきれい。標準 20)と `preset`(遅いほど小さい。標準 medium)で変えられる。

## 設定

ゲームのフォルダーの `config/povreplay.properties`(初回の動画化で自動的にできる)。

```
width=1920     # 動画の幅(ウィンドウの大きさに関係なく、この大きさで描く)
height=1080    # 動画の高さ
matrix=bt709   # 色の式。bt709(標準)か bt601
range=limited  # 明るさの範囲。limited(16〜235、標準)か full(0〜255)
ffmpeg=auto    # auto = 探して、あれば使う / off = 使わない / ffmpeg の場所
crf=20         # ffmpeg の画質。小さいほどきれい(18 = ほぼ劣化なし、20 = 標準、23 = ふつう、26 = 軽い)
preset=medium  # ffmpeg の速さ(ultrafast 〜 slower。遅いほど小さい)
videoArgs=     # 上級者向け: 映像の圧縮の指定を、まるごと書き換える(例 -c:v h264_nvenc -preset p5 -cq 22)
qp=18          # 内蔵のエンコーダーの画質(10〜40。大きいほど、小さく・粗くなる)
```

大きくするほど、動画にするのに時間がかかる。

## 動画の形式

MP4(H.264 + AAC 44.1kHz)。ffmpeg がなくても書き出せる(内蔵のエンコーダーは、MOD の中に入っている)。ffmpeg があれば、ffmpeg で圧縮する(ファイルが、ずっと小さくなる)。

## できないこと・注意

- **録画できるのは、ワールドに入っている間だけ**(記録は、ワールドに入った瞬間から取っている。途中から録画を始めても、そこまでの記録を使って、ワールドを組み立てるので、大丈夫)。
- 書き出すとき、ワールドを一度出る。何回か録画しておいて、あとから、まとめて書き出すとよい(最大 10 件)。
- プレイヤー自身の動きで、記録に残らないもの: 自分が掘っているブロックのひび割れ、自分の足音など(音は、聞こえたとおりに録音しているので、動画の音には入る)。
- 記録に使うディスク: 通信の記録は、遊んだ時間に比例して大きくなる(動画にしない記録は、ワールドを出たときに消える)。
- 通信の形式は、ゲームのバージョンごとに違う。録画したバージョンと同じバージョンで、動画にすること。

## ビルド

`.github/workflows/build-povreplay.yml`(Actions タブから実行。jar は `replaymod/dist/` に保存される)。Minecraft 26.3、Fabric Loader 0.20 以降、Fabric API が必要。
