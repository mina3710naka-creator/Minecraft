# povreplay(POV Replay)

Minecraft(Fabric)用の、クライアント専用 MOD。**リプレイ方式**の録画: プレイ中は、ゲームの通信とプレイヤー視点の状態を**記録するだけ**(とても軽い)。止めたあと、ワールドを出ると、記録を**再生し直して、高画質の動画(音つき)にする**。視点は、プレイヤー視点だけ。

(画面をそのまま動画にする MOD は `../recmod`。この MOD と同時には入れない — メニューのボタンが重なる。)

## 使い方

1. ワールドに入って、Esc でメニューを開く。左上に **「● 録画」** ボタンがある。押すと録画を始める。
2. 録画中は、画面の左上に「● REC 0:12」が出る(動画には映らない)。もう一度 Esc → **「■ 停止」**。
3. 止めると、「ここからここまで」を覚える(保存待ち)。**ワールドから出る**(メニューの「**保存して出る**」、またはふつうに「保存してタイトルへ」)と、自動で、動画にして保存する。
   - 動画にしている間は、ワールドを再生し直している画面が出る。進み具合と、3 つのボタンがある:
     - **最小化**(右上の「－」でも): 進み具合と「拡大」のボタンだけを、画面の右上に残す。「拡大」(または Esc)で、元の大きさに戻る。
     - **プレビュー: 入/切**: 再生しているワールドを、背景に見せるか(切にすると、背景が真っ黒になる)。
     - **中止**: 動画にするのをやめる。この録画は削除される。
   - 終わると、タイトル画面に戻る。
   - 動画への変換は、そのあと、裏で続く(ゲームは遊べる)。終わると、画面の隅に通知が出る。
4. **保存先**: ユーザーフォルダーの `Downloads` フォルダー(Windows なら `C:\Users\(ユーザー名)\Downloads`)。なければ、ゲームのフォルダーの `recordings/`。ファイル名: `minecraft-日時.mp4`。
   - 保存し終わるまで、**画面の右上**に「動画を保存中 72%」と進み具合を出し続ける(ワールドの中でも、タイトル画面でも)。終わると、保存した場所を 15 秒ほど出す。
5. 保存待ちのままゲームを閉じても、消えない。次にゲームを起動すると、タイトル画面で、続きを始める。保存できなかった録画(失敗・中止)は、保存待ちに残さず、ファイルごと削除する。

## しくみ

- **プレイ中**(軽い): サーバーからゲームに届いた通信を、そのままの形で、時刻をつけて、ファイル(`povreplay/sessions/`)に書く(圧縮も、優先度の低い別のスレッドでする)。録画中は、描画のたびに、プレイヤー視点の状態(カメラの位置と向き・視野角・手の動き・歩くときの揺れなど。1 回 約 150 バイト)も書く。音は、聞こえたとおりに混ぜて、圧縮せずに、ファイルに書く。画面の絵は、取らない。
- **動画にするとき**: 本物のサーバーの代わりに、記録した通信を、偽の接続からゲームに流し込んで、ワールドを組み立て直す(シングルプレイでもマルチプレイでも同じ)。ゲームの時計を、1 フレームごとに 1/30 秒だけ進む仮想の時計にして、1 フレームずつ描き、絵を取る。絵を取り終わるまで時計を進めないので、重い場面でも、絵は飛ばず、いつも 30fps になる。視点と手の動きは、記録した値で上書きする。
- ウィンドウの大きさに関係なく、設定した大きさ(標準 1920x1080)で描き直すので、画面を小さくして遊んでいても、フルサイズの動画になる。

## 設定

ゲームのフォルダーの `config/povreplay.properties`(初回の動画化で自動的にできる)。画質(量子化の数値)は 18 で固定。

```
width=1920     # 動画の幅(ウィンドウの大きさに関係なく、この大きさで描く)
height=1080    # 動画の高さ
matrix=bt709   # 色の式。bt709(標準)か bt601
range=limited  # 明るさの範囲。limited(16〜235、標準)か full(0〜255)
```

大きくするほど、動画にするのに時間がかかる。

## 動画の形式

MP4(H.264 + AAC-LC 44.1kHz)。ffmpeg などの外部ソフトは要らない(エンコーダーは MOD の中に入っている)。映像は、0.5 秒ごとのキーフレームと、その間の差分で作る。

## できないこと・注意

- **録画できるのは、ワールドに入っている間だけ**(記録は、ワールドに入った瞬間から取っている。途中から録画を始めても、そこまでの記録を使って、ワールドを組み立てるので、大丈夫)。
- 動画にするとき、ワールドを一度出る。録画ごとにワールドを出るのが面倒なら、何回か録画して、最後にまとめて「保存して出る」とよい。
- プレイヤー自身の動きで、記録に残らないもの: 自分が掘っているブロックのひび割れ、自分の足音など(音は、聞こえたとおりに録音しているので、動画の音には入る)。
- 記録に使うディスク: 通信の記録は、遊んだ時間に比例して大きくなる(動画にしない記録は、ワールドを出たときに消える)。
- 通信の形式は、ゲームのバージョンごとに違う。録画したバージョンと同じバージョンで、動画にすること。

## ビルド

`.github/workflows/build-povreplay.yml`(Actions タブから実行。jar は `replaymod/dist/` に保存される)。Minecraft 26.3、Fabric Loader 0.20 以降、Fabric API が必要。
