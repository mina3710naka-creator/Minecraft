# Lamp Video MOD（レッドストーンランプ動画）

動画を、レッドストーンランプの点灯/消灯（白黒）で再生する Fabric MOD です。
映像の**暗い部分が点灯、明るい部分が消灯**です（線画なら線が光ります）。
データパックと違って、動画データを**外部ファイルから少しずつ読む**ので、`/reload` やワールドを開くときに重くなりません。

## 使い方（jar を入れるだけ）
1. `lampvideomod/dist/lampvideomod-mc26.3.jar` を、`.minecraft/mods/` に入れます（Fabric Loader と Fabric API が必要です）。
2. ワールドに入って、平らな場所で次を実行します。
   ```
   /lampvideo start
   ```
   足元が画面の左下角になります。**南側から北を向いて**見てください。音声も鳴ります。

jar には、サンプル動画（240×240、約11分30秒、全フレームを3tickずつ表示）と音声、ランプの単色テクスチャが入っています。
**動画ファイルやリソースパック、データパックは要りません。**
画面の高さが240ブロックあるので、Y=80 以下の場所で実行してください（通常の地形なら大丈夫です）。

## 自分の動画を再生する
`.minecraft/lampvideo/` フォルダ（MOD が自動で作ります）に、動画ファイル（mp4・mkv・webm・mov など）を入れるだけです。

- ワールドを開くと、未変換の動画が**自動で変換**されます。`/lampvideo convert` で、その場でも変換できます。
- 変換が終わると、チャットに知らせが出ます。`/lampvideo list` で名前を確認して、`/lampvideo start <名前>` で再生します。
- 名前は、ファイル名から作ります（小文字の英数字と `_`。日本語などは `_` になります）。
- **変換には ffmpeg が必要です**（PC にインストールして、PATH を通してください。Windows なら `winget install ffmpeg`）。
  ffmpeg がなくても、同梱のサンプルは再生できます。
- 変換した動画の**音声**を鳴らすには、リソースパック `lampvideo_audio`（`.minecraft/resourcepacks/` に自動で作られます）を一度有効にして、
  F3+T でリソースを再読み込みします。映像だけなら不要です。
- 画面は 240 ブロック幅、各フレームを 3tick（約0.28倍速）で作ります。

## コマンド
| コマンド | 内容 |
| --- | --- |
| `/lampvideo start [名前]` | 足元に画面を作って、すぐ再生（名前を省略するとサンプル） |
| `/lampvideo setup <名前>` / `play` | 画面を作る / 再生する（分けて実行したいとき） |
| `/lampvideo stop` / `remove` | 停止 / 画面を片付ける |
| `/lampvideo list` | 再生できる動画の一覧 |
| `/lampvideo convert` | フォルダの未変換の動画を、いま変換する |

コマンドの権限は設定していません。サーバーで使う場合は、オペレーター以外も実行できます。

## ビルド
GitHub の Actions（`Build lampvideomod`）で、jar をビルドして `lampvideomod/dist/` に保存します。
手動実行のとき、Minecraft のバージョンを指定できます（既定 26.3）。

## 動画ファイル（.lvf）を直接作る
変換は MOD が自動でやりますが、Python のツールでも作れます。
```
pip install numpy pillow     # ffmpeg も必要
python3 ../lampvideo/make_lvf.py input.mp4 --out out --name myvideo --width 360 --hold 3
```
できた `myvideo.lvf` を `.minecraft/lampvideo/` に置くと、`/lampvideo start myvideo` で再生できます（`sample/video360.lvf` が360版の例です。360版は Y=-40 以下で実行してください）。

## 仕組み（メモ）
- ランプは、隣のブロックに通知しない設定（`setBlock` のフラグ2）で `lit` を直接切り替えます。
  無電力で点灯したランプが約4tick後に勝手に消える現象は、隣への通知があるときだけ起きるので、これで防げます。
- フレームは、前のフレームとの差分の長方形だけを持ちます。100フレームで全面を1周描き直し（帯状に少しずつ）、書き込みに失敗しても直ります。
- 手前に明るさ15の光源ブロックを敷いて、ランプ面の明るさを一定にします（明暗のムラ防止）。
- 形式は `src/main/java/com/lampvideo/LvfVideo.java` の説明を参照してください。

> 実際の Minecraft 26.3 では、まだ動かしていません。ビルド（コンパイル）は成功しています。動かないところがあれば、教えてください。
