# スパイダークロスボウ (Spider Crossbow) — Minecraft データパック

クロスボウを構えて糸を撃ち出し、**スパイダーマンのようにワイヤーアクションで移動**したり、
**着弾地点にクモの巣を張って罠にしたり**できるデータパックです。専用の
「クモの巣クリアボール」を投げると、命中したクモの巣を塊ごと除去できます。
すべて `function`（コマンド）で実装しています。

対応バージョン: Minecraft Java Edition 26.2（データパック形式 107 / `min_format` `max_format` 方式）

---

## 導入方法

1. `spidercrossbow` フォルダを、ワールドの `datapacks` フォルダにコピーします。

   ```
   .minecraft/saves/<ワールド名>/datapacks/spidercrossbow/
   ├── pack.mcmeta
   └── data/
   ```

2. ワールドに入って `/reload` を実行します。
   `[スパイダークロスボウ] 読み込み完了` と表示されれば成功です。

3. アイテムを受け取ります。

   ```
   /function sc:give
   ```

   スパイダークロスボウ1本（クイックチャージV・無限付き）、矢1本、
   巣づくりモード用の糸64個、クモの巣クリアボール16個が配布されます。
   矢は無限エンチャントで消費されないため、以降は手動でのリロードなしで
   撃ち続けられます。

4. 操作方法は `/function sc:help` でいつでも確認できます。

> 通常のクロスボウ・雪玉はそのまま使えます。このデータパックが反応するのは
> `custom_data` に専用フラグ（`sc_crossbow` / `sc_ball`）が付いた専用アイテムを
> 持っているときだけです。

### アンインストール

```
/function sc:uninstall
```
を実行してから、データパックのフォルダを削除してください。

## 操作方法

クロスボウは**クイックチャージV＋無限**エンチャント付きで配布されるため、矢を1本
持たせておけば**自動的にずっと装填され続け**、手動でのリロードは不要です。

| 操作 | 内容 |
| --- | --- |
| 右クリック | 現在のモードで発射（構えるとほぼ一瞬で装填完了） |
| Shiftタップ（フックしていない時） | モード切替（フックショット ⇔ 巣づくり） |
| クモの巣クリアボールを投げる | 命中したクモの巣を塊ごと除去する |

右クリックで実際に矢が出現した瞬間を発射の合図にしていますが、**実際に飛んでいく
のは矢そのものではありません**。矢はその場でキルし、代わりに自分の現在の視点方向から
新しく雪玉ベースの発射物を生成します（矢自身の位置・向きに頼ると、以前バージョンで
「たまたま近くにあった古い矢を誤って掴んでしまい、変な方向へ飛ぶ」不具合が起きたため、
`ball/fire.mcfunction`と同じ、実機で確実に動く「自分の視点から生成する」方式に統一
しています）。

### モード1: フックショット

右クリックで視点方向へ雪玉ベースの弾を発射し、**最大100ブロック**まっすぐ飛ばして
**白いエフェクト**（雲・エンドロッドの粒子）を残します。

* **ブロックに命中** → その場に固定され、綱で吊り下げられたように振り子で移動できます。
  **見た方向へ徐々に振れていく**ので、登りたい方向・振れたい方向を見ながら移動してください。
* **MOB に命中** → 自分ではなく **MOB の方が自分側へ引き寄せられます**（最大5秒、または1.8ブロック以内に近づくと終了）。

フック中の操作:

| 操作 | 内容 |
| --- | --- |
| 持ち替えキー（デフォルト: F、「アイテムを交換」） | 綱を巻き取る（アンカーに近づく） |
| Shift + 持ち替えキー | 綱を伸ばす（アンカーから離れる） |
| ジャンプ、またはShiftタップ | 解除。真上に約5マス打ち上げる |
| もう一度右クリック | 解除（バックアップ操作。ジャンプ/Shiftタップと同じ効果） |

フック中は持ち替えキーが巻き取り／伸ばす操作専用になり、モード切替はできません。

### モード2: 巣づくり

右クリックで糸を1個消費して発射します。着弾したブロックや MOB の位置に
**3×3×3 のクモの巣**を設置します。糸を持っていないと発射できません。
フックショットと同様、最大100ブロック飛ばし、白いエフェクトを残します。

### クモの巣クリアボール

専用の雪玉（`/function sc:give`で入手）を普通に**投げる**と発動します。
視点方向へ**一定速度（1ブロック/tick）でゆっくり、最大50ブロック**まで飛び続け、
見失わないようにしています。**クモの巣に当たると、繋がっている塊ごと**
（最大240ブロックまで）除去します。クモの巣以外（壁など）に当たると特に見た目の
変化はなく消えます。

## 実装メモ・バニラの仕様上の制約

このデータパックは、このリポジトリの `hookshot` / `ultimateweapon` / `opboots` で
実機検証済みの手法を組み合わせて作られています。特に重要な制約は以下の通りです。

* **`execute at <対象>` は位置だけを引き継ぎ、向き（rotation）は引き継がない** —
  毎tick処理の入口で `execute as @a at @s run function ...` と書いていたところ、
  発射方向が常に「南」（Minecraftのyaw=0の方向）に固定されてしまう不具合がありました。
  `at` は実行位置とディメンションだけを対象に合わせるコマンドで、向きは変更しない
  ため、`tick.mcfunction` の呼び出し元（`minecraft:tick` 関数タグ、向きを持たない）
  の既定の向き（yaw=0=南）がそのまま残っていたのが原因です。`rotated as @s` を
  明示的に追加し、実行者（プレイヤー）の実際の視点を向きとして引き継ぐように
  修正しました（`tick.mcfunction`）。
* **発射物は矢や雪玉そのものではなく、検知した瞬間に自分の視点から作り直す** —
  右クリックの発射検知は、統計や `execute on owner` が実機で不安定だったため、
  クロスボウ/クモの巣クリアボールを持っているプレイヤー自身を毎tick直接確認し、
  近く（2ブロック以内）に未処理の矢・雪玉が出現していないか調べる方式にしています
  （`detect_shot.mcfunction` / `check_fire.mcfunction`、`detect_throw.mcfunction` /
  `check_throw.mcfunction`。`ultimateweapon`パックの実機テストで確立された手法）。
  見つけた本物の矢・雪玉はその場でキルするだけで、**位置や向きには一切頼りません**。
  実際に飛んでいく発射物は、検知した瞬間の**自分の視点方向**から改めて生成します
  （`hook/fire.mcfunction` / `web/fire_do.mcfunction` / `ball/fire.mcfunction` が
  すべて同じ `anchored eyes positioned ^0.3 ^-0.2 ^0.7 summon minecraft:snowball`
  パターンを使っています）。
  * 以前のバージョンでは「検知した本物の矢自身の位置・向きをそのまま使う」方式に
    していましたが、**2ブロック以内という判定条件では、たまたま近くに落ちていた
    無関係な古い矢を誤って掴んでしまうことがあり**、その矢の向きのまま（＝見当違いの
    方向へ）発射物が飛んでしまう不具合がありました。「自分の視点から作り直す」方式は
    この問題を根本的に回避できます。
* **「R」「Shift+R」キーはバニラに存在しない** — バニラのMinecraftには初期状態で
  何も割り当てられていない「R」というキー入力自体を、データパック（コマンド）から
  直接検知する方法がありません。そこで本パックは、確実に検知できる
  **「アイテムを交換」キー（デフォルト: F）でメインハンドとオフハンドの中身が
  入れ替わった瞬間**を「Rキーが押された」の代わりとして使っています
  （フック中のみ有効。Shiftを押しながらなら「伸ばす」、押していなければ「巻き取り」）。
  文字通り「R」キーで操作したい場合は、Minecraftの操作設定で
  「アイテムを交換」を「R」に割り当て直してください（ゲーム内の設定変更のみで、
  データパック側の変更は不要です）。
* **スペースキー（ジャンプ）は空中では判定できない** — これは `opboots` の実装メモにも
  ある通り、バニラの仕様上の制約です。ジャンプキーの入力（統計
  `minecraft.custom:minecraft.jump`）は、**すでに空中にいる間はそもそも増加しません**。
  フック中は基本的に空中にいることが多いため、スペースキーでの解除は
  **足が地面についている瞬間だけ**有効になります。空中でも確実に解除できるよう、
  代わりに **Shiftを軽くタップする**操作、および**もう一度右クリックする**操作を
  解除のバックアップとして用意しています（`mode/edge.mcfunction` /
  `on_shot.mcfunction`）。
* **プレイヤーの `Motion`（速度）NBTは直接書き換えられない** — これも `hookshot` /
  `opboots` の実装メモの通りで、実在するプレイヤーの移動速度をコマンドで
  直接操作することはできません。そのため振り子の移動は、`hookshot` の
  引き寄せ処理と同じく、**見えない台車（コウモリ）にプレイヤーを `ride` で
  乗せ、台車の方だけを `tp` で動かす**方式を使っています。
* **振り子の物理演算は簡易モデル** — 本格的な重力シミュレーション（速度・慣性を
  持った振り子運動）は、平方根を使わずにコマンドだけで正確に実装するのが
  非常に難しいため、本パックでは **「アンカーからの距離（綱の長さ）と、
  プレイヤーの視点の向き（ヨー・ピッチ）」から毎tick位置を再計算する**、
  よりゲーム的なモデルを採用しています。**見た方向へ振れ／登り、
  巻き取り・伸ばすで距離を操作する**という、意図的な操作感を重視した設計です。
  真下を向くと綱の下へ、上を見ると綱の高さ付近まで振れます。
  `execute at <アンカー> rotated <yaw> <pitch> positioned ^ ^ ^<綱の長さ> run tp` という、
  バニラの座標変換をそのまま利用したテクニックで、平方根や三角関数を
  自前計算する必要を避けています。
* **クモの巣クリアボールをShift+左クリックではなく「投げる」専用アイテムにした理由** —
  当初は「クロスボウを持ちながら左クリック」で発動する方式にしていましたが、左クリックの
  検知には `minecraft:interaction` エンティティが必要で、これを常駐させると本物の
  クロスボウの「構える」動作を横取りしてしまい**右クリックが完全に効かなくなる**ことが
  実機で確認されました（`ultimateweapon`の実装メモにあった既知の注意点の再現）。
  Shiftを押している間だけ配置する回避策も試しましたが、Shiftキーがモード切替とも
  競合し複雑になるため、最終的に**専用の投げアイテム**（普通の雪玉を投げる操作）に
  変更しました。これによりインタラクションエンティティが一切不要になり、
  クロスボウの右クリックと完全に独立して動作します。
* **MOB引き寄せ中はNoAIになる** — フックが刺さったMOBは引き寄せられている間
  `NoAI` になり、攻撃や逃走ができなくなります（引き寄せ終了時に元に戻します）。
* **クモの巣の除去判定はブロックが空気になったことで管理** — フラッドフィルの
  訪問済み判定に専用のタグ管理は使わず、「壊した箇所はもうクモの巣ではなくなる」
  という性質を利用しています（`ball/flood_step.mcfunction`）。無限ループの
  心配がなく、最大240ブロックの安全上限もついています。

## ファイル構成

```
spidercrossbow/
├── pack.mcmeta
└── data/
    ├── minecraft/tags/function/   … tick / load への登録
    └── sc/
        ├── predicate/sneaking.json
        ├── tags/block/passable.json   … フック・巣づくり弾が貫通するブロック
        ├── loot_table/give/           … クロスボウの配布
        └── function/
            ├── load / tick / give / help / uninstall
            ├── detect_shot / check_fire / on_shot     … クロスボウの発射検知・モード別発射
            ├── detect_throw / check_throw             … クモの巣クリアボールの投擲検知
            ├── mode/    … Shiftでのモード切替・フック中の解除
            ├── input/   … 持ち替えキーでのフック中の巻き取り／伸ばす検知
            ├── hook/    … モード1: フック発射・振り子・MOB引き寄せ・解除
            ├── web/     … モード2: 巣づくり（3x3x3のクモの巣設置）
            ├── ball/    … クモの巣クリアボール（フラッドフィル除去）
            └── util/    … 後始末・安全装置
```
