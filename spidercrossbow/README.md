# スパイダークロスボウ (Spider Crossbow) — Minecraft データパック

クロスボウを構えて糸を撃ち出し、**スパイダーマンのようにワイヤーアクションで移動**したり、
**着弾地点にクモの巣を張って罠にしたり**、**特別な球でクモの巣を除去したり**できる
データパックです。すべて `function`（コマンド）で実装しています。

対応バージョン: Minecraft Java Edition 26.2（データパック形式 107 / `min_format` `max_format` 方式）

---

## 導入方法

1. `spidercrossbow` フォルダを、ワールドの `datapacks` フォルダにコピーします。

   ```
   .minecraft/saves/<ワールド名>/datapacks/spidercrossbow/
   ├── pack.mcmeta
   └── data/
   ```

2. ワールドに入って `/reload` を実行します。
   `[スパイダークロスボウ] 読み込み完了` と表示されれば成功です。

3. アイテムを受け取ります。

   ```
   /function sc:give
   ```

   スパイダークロスボウ1本（クイックチャージV・無限付き）、矢1本、
   巣づくりモード用の糸64個が配布されます。矢は無限エンチャントで消費されないため、
   以降は手動でのリロードなしで撃ち続けられます。

4. 操作方法は `/function sc:help` でいつでも確認できます。

> 通常のクロスボウはそのまま使えます。このデータパックが反応するのは
> `custom_data` に `sc_crossbow` が付いた専用のクロスボウを持っているときだけです。

### アンインストール

```
/function sc:uninstall
```
を実行してから、データパックのフォルダを削除してください。

---

## 操作方法

クロスボウは**クイックチャージV＋無限**エンチャント付きで配布されるため、矢を1本
持たせておけば**自動的にずっと装填され続け**、手動でのリロードは不要です。

| 操作 | 内容 |
| --- | --- |
| 右クリック | 現在のモードで発射（構えるとほぼ一瞬で装填完了） |
| Shift（タップ／フックしていない時） | モード切替（フックショット ⇔ 巣づくり） |
| Shift + 左クリック | いつでも特別な球を発射。命中したクモの巣を塊ごと除去する |

> 左クリックの検知には`minecraft:interaction`エンティティを使っていますが、
> これを常駐させると本物のクロスボウの「構える」動作を横取りしてしまい
> **右クリックが完全に効かなくなる**ことが実機で確認されたため、Shiftを
> 押している間だけ配置する方式に戻しました。Shiftは「モード切替」と
> 「特別な球の修飾キー」を兼ねています。押した瞬間はすぐに切り替えず
> 一瞬（0.2秒）だけ保留し、その間にShift+左クリックがあれば特別な球だけを
> 発動してモード切替は取り消す、無ければ（またはShiftを離せば）モードを
> 切り替える、という判定にしています（`mode/pend_start.mcfunction` /
> `mode/pend_tick.mcfunction`）。

### モード1: フックショット

右クリックで視点方向へ発射します。発射を検知した瞬間、その本物の矢を
**透明な防具立てに変換**（矢は消して、位置・向きをそのまま引き継ぐ）し、
以降は毎tickこちらで真っ直ぐ歩かせて**最大100ブロック**飛ばし、
**白いエフェクト**（雲・エンドロッドの粒子）を残します。

* **ブロックに命中** → その場に固定され、綱で吊り下げられたように振り子で移動できます。
  **見た方向へ徐々に振れていく**ので、登りたい方向・振れたい方向を見ながら移動してください。
* **MOB に命中** → 自分ではなく **MOB の方が自分側へ引き寄せられます**（最大5秒、または1.8ブロック以内に近づくと終了）。

フック中の操作:

| 操作 | 内容 |
| --- | --- |
| 持ち替えキー（デフォルト: F、「アイテムを交換」） | 綱を巻き取る（アンカーに近づく） |
| Shift + 持ち替えキー | 綱を伸ばす（アンカーから離れる） |
| ジャンプ、またはShiftを軽くタップ | 解除。真上に約5マス打ち上げる |
| もう一度右クリック | 解除（バックアップ操作。ジャンプ/Shiftタップと同じ効果） |

フック中は持ち替えキーがモード切替ではなく巻き取り／伸ばす操作になります。

### モード2: 巣づくり

右クリックで糸を1個消費して発射します。着弾したブロックや MOB の位置に
**3×3×3 のクモの巣**を設置します。糸を持っていないと発射できません。
フックショットと同様、本物の矢を最大100ブロック飛ばし、白いエフェクトを残します。

### 特別な球（Shift + 左クリック）

クロスボウを持ちながら **Shift を押している間だけ**、左クリックで発射できます。
視点方向へ飛んでいき、**クモの巣に当たると、繋がっている塊ごと**（最大240ブロックまで）除去します。
クモの巣以外（壁など）に当たると特に見た目の変化はなく消えます
（発射した瞬間の雪玉投擲音・パーティクルは出ます）。

## 調整できる数値

| 内容 | ファイル | 該当箇所 |
| --- | --- | --- |
| フックの速さ・射程 | `hook/tick.mcfunction` / `hook/step.mcfunction` | `sc.sub 20`（5.0ブロック/tick）、`sc.range matches 400..`（100ブロック） |
| MOBへの自動吸着範囲 | `hook/step.mcfunction` | `distance=..3` |
| 振り子の旋回速度 | `hook/swing_tick2.mcfunction` | 水平方向は1tickあたり最大10度、垂直方向は最大5度 |
| 振り子の綱の長さ範囲 | `hook/carrier_init.mcfunction` / `reel_in_do` / `reel_out_do` | 最小12（3ブロック）〜最大240（60ブロック）、1回の巻き取り/伸ばしで8（2ブロック） |
| 解除時のジャンプの高さ | `hook/release.mcfunction` / `hook/launch_tick.mcfunction` | `levitation 4 23 true`（amplifier）／ 7tickで効果を切る（約5マス相当。opboots/hookshotと同じ手法・同じ計算） |
| MOB引き寄せの速度・制限時間 | `hook/mobpull_tick2.mcfunction` | `tp @s ^ ^ ^0.4`（0.4ブロック/tick）、`sc.t matches 100..`（5秒） |
| フックの安全装置（強制解除） | `hook/release_check.mcfunction` | `sc.hookt matches 600..`（30秒） |
| 巣づくりの射程・範囲 | `web/step.mcfunction` / `web/hit2.mcfunction` | `sc.range matches 400..`（100ブロック）、`fill ~-1 ~-1 ~-1 ~1 ~1 ~1` |
| 特別な球の射程・除去上限 | `ball/step.mcfunction` / `ball/flood_step.mcfunction` | `sc.range matches 240..`（60ブロック）、`sc.ballc matches ..240`（240ブロック） |
| 通り抜けるブロック | `data/sc/tags/block/passable.json` | 草・水・松明などフックが貫通するブロック |
| 対応バージョン範囲 | `pack.mcmeta` | `min_format` / `max_format`（26.2 = 107） |

## 実装メモ・バニラの仕様上の制約

このデータパックは、このリポジトリの `hookshot` / `ultimateweapon` / `opboots` で
実機検証済みの手法を組み合わせて作られています。特に重要な制約は以下の通りです。

* **「R」「Shift+R」キーはバニラに存在しない** — バニラのMinecraftには初期状態で
  何も割り当てられていない「R」というキー入力自体を、データパック（コマンド）から
  直接検知する方法がありません。そこで本パックは、確実に検知できる
  **「アイテムを交換」キー（デフォルト: F）でメインハンドとオフハンドの中身が
  入れ替わった瞬間**を「Rキーが押された」の代わりとして使っています
  （フック中のみ有効。Shiftを押しながらなら「伸ばす」、押していなければ「巻き取り」）。
  文字通り「R」キーで操作したい場合は、Minecraftの操作設定で
  「アイテムを交換」を「R」に割り当て直してください（ゲーム内の設定変更のみで、
  データパック側の変更は不要です）。
  * 持ち替え自体は検知にしか使っておらず、アイテムの位置（メインハンド/オフハンド）を
    強制的に戻すような処理はしていません。持ち替えた状態のまま使い続けても、
    クリック検知・発射検知はどちらの手に持っていても機能します。
* **実機で見つかった2つのバグ（Shiftのモード切替・左クリックが反応しない原因）** —
  「Shiftを押しても切り替わらない」「左クリックしても何も起こらない」という
  不具合の原因は、`ultimateweapon`パックで実際に確認・修正済みの、次の2つの
  既知の落とし穴と同じものでした。
  1. **クリック検知エンティティの座標指定ミス** — `anchored eyes positioned ~ ~-0.6 ~`
     と書いていたが、`anchored eyes`の直後は`^`（視線方向基準の相対座標）で
     指定しないと意味がなく、`~`（現在位置＝足元基準の相対座標）のままだと
     視点ではなく**足元の下**にエンティティが出現してしまい、絶対にクリックできて
     いなかった。`^ ^-0.6 ^`に修正（`click/spawn.mcfunction` / `click/ensure.mcfunction`）。
  2. **`execute on owner`が実機で反応しない** — 発射された矢から
     `execute on owner ... run function ...`で持ち主を辿る方式は、実際の
     クライアントでは発火しないことがあるため、モード切替の判定と同じ
     「専用アイテムを持っているプレイヤー自身を毎tick直接確認し、自分の
     近く（2ブロック以内）に未処理の矢が出現していないか調べる」方式に
     変更（`detect_shot.mcfunction` / `check_fire.mcfunction`）。
* **スペースキー（ジャンプ）は空中では判定できない** — これは `opboots` の実装メモにも
  ある通り、バニラの仕様上の制約です。ジャンプキーの入力（統計
  `minecraft.custom:minecraft.jump`）は、**すでに空中にいる間はそもそも増加しません**。
  フック中は基本的に空中にいることが多いため、スペースキーでの解除は
  **足が地面についている瞬間だけ**有効になります。空中でも確実に解除できるよう、
  代わりに **Shiftを軽くタップする**操作、および**もう一度右クリックする**操作を
  解除のバックアップとして用意しています（`mode/toggle.mcfunction` /
  `on_shot.mcfunction`）。
* **プレイヤーの `Motion`（速度）NBTは直接書き換えられない** — これも `hookshot` /
  `opboots` の実装メモの通りで、実在するプレイヤーの移動速度をコマンドで
  直接操作することはできません。そのため振り子の移動は、`hookshot` の
  引き寄せ処理と同じく、**見えない台車（コウモリ）にプレイヤーを `ride` で
  乗せ、台車の方だけを `tp` で動かす**方式を使っています。
* **振り子の物理演算は簡易モデル** — 本格的な重力シミュレーション（速度・慣性を
  持った振り子運動）は、平方根を使わずにコマンドだけで正確に実装するのが
  非常に難しいため、本パックでは **「アンカーからの距離（綱の長さ）と、
  プレイヤーの視点の向き（ヨー・ピッチ）」から毎tick位置を再計算する**、
  よりゲーム的なモデルを採用しています。**見た方向へ振れ／登り、
  巻き取り・伸ばすで距離を操作する**という、意図的な操作感を重視した設計です。
  真下を向くと綱の下へ、上を見ると綱の高さ付近まで振れます。
  `execute at <アンカー> rotated <yaw> <pitch> positioned ^ ^ ^<綱の長さ> run tp` という、
  バニラの座標変換をそのまま利用したテクニックで、平方根や三角関数を
  自前計算する必要を避けています。
* **右クリックは本物のクロスボウの装填・発射をそのまま使う** — 右クリックでの
  発射は**本物のクロスボウの構え→矢の出現をそのまま使う方式**にしています。
  `ultimateweapon` のクロスボウと同様、クイックチャージV・無限を付与し
  （`loot_table/give/crossbow.json`）、**実際に矢が出現した瞬間**を発射の合図に
  しています（`detect_shot.mcfunction` / `check_fire.mcfunction` / `on_shot.mcfunction`）。
  * **本物の矢を防具立てに変換して飛ばす** — 見つけた本物の矢はその場で
    キルし、代わりに**同じ位置・同じ向きの透明な防具立て**を生成して、
    フックショット本来の仕組み（`hook/step.mcfunction`のtp移動＋白い
    パーティクル）でまっすぐ飛ばします（`hook/init.mcfunction` /
    `web/init.mcfunction`）。矢自体は無限エンチャントで消費されないため、
    矢を1本持たせておけば手動リロードなしでずっと撃ち続けられます。
  * **古い矢の誤検知対策** — 発射検知（`check_fire.mcfunction`）は
    「2ブロック以内の未処理の矢」を拾う方式のため、地面に刺さって
    止まっている**古い矢**にたまたま近づいただけで誤って拾ってしまうと、
    その古い矢の向きのまま（＝見当違いの方向へ）フックが飛ぶ不具合が
    起こり得ます。地面に刺さって止まっている矢（`inGround:1b`）は対象から
    除外していますが、**すでにワールドに散らばっている古い矢**が残っている
    場合は、念のため `/kill @e[type=minecraft:arrow]` で一度片付けてから
    お試しください。
* **左クリックの検知には `minecraft:interaction` エンティティを使用（Shiftを
  押している間だけ）** — 通常の左クリック（振り攻撃）は何かに命中しない限り
  サーバー側でほぼ検知できないため、`ultimateweapon` の最強のダイヤの剣と
  同じ方式で、プレイヤーの視点位置に透明なインタラクションエンティティを
  配置し、その `attack` フィールドの変化で左クリックを検知しています
  （`click/`）。
  * 一度「素の左クリックで発射したい」という要望に合わせてこのエンティティを
    **常駐**させたところ、実機で**右クリックが完全に構えられなくなる**
    （インタラクションエンティティが本物の「構える」動作を横取りしてしまう）
    ことが確認されました。`ultimateweapon`の実装メモにあった注意点が
    そのまま再現された形です。そのため常駐はやめ、**Shiftを押している間だけ**
    視点位置に配置する方式に戻しています（`click/ensure.mcfunction`）。
    Shiftを離せば即座に消え、通常通り右クリックでクロスボウを構えられます。
    この結果、特別な球は **Shift+左クリック**が実際の操作方法になっています。
* **MOB引き寄せ中はNoAIになる** — フックが刺さったMOBは引き寄せられている間
  `NoAI` になり、攻撃や逃走ができなくなります（引き寄せ終了時に元に戻します）。
* **クモの巣の除去判定はブロックが空気になったことで管理** — フラッドフィルの
  訪問済み判定に専用のタグ管理は使わず、「壊した箇所はもうクモの巣ではなくなる」
  という性質を利用しています（`ball/flood_step.mcfunction`）。無限ループの
  心配がなく、最大240ブロックの安全上限もついています。

## ファイル構成

```
spidercrossbow/
├── pack.mcmeta
└── data/
    ├── minecraft/tags/function/   … tick / load への登録
    └── sc/
        ├── predicate/sneaking.json
        ├── tags/block/passable.json   … フック・巣づくり弾が貫通するブロック
        ├── loot_table/give/           … クロスボウの配布
        └── function/
            ├── load / tick / give / help / uninstall
            ├── detect_shot / check_fire / on_shot   … 本物のクロスボウの発射検知・モード別発射
            ├── click/   … 左クリック(Shift併用)の検知（インタラクションエンティティ）
            ├── mode/    … Shiftでのモード切替（保留判定）・フック中の解除
            ├── input/   … 持ち替えキーでのフック中の巻き取り／伸ばす検知
            ├── hook/    … モード1: フック発射・振り子・MOB引き寄せ・解除
            ├── web/     … モード2: 巣づくり（3x3x3のクモの巣設置）
            ├── ball/    … 特別な球（クモの巣のフラッドフィル除去）
            └── util/    … 後始末・安全装置
```
