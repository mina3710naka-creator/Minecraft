# Song Builder(曲を音符ブロックの回路にする MOD)

mp3 / mp4 の曲を音程に変換し、**リピーターと音符ブロックの演奏回路**をマイクラ内に建てる Fabric MOD です。

## 手順
1. 曲を JSON に変換する(ffmpeg と Python が必要)。**一度に変換するのは、1 曲ずつです。**
   - **いちばん簡単: `tools/convert.bat`(Mac / Linux は `convert.sh`)に、ファイルをドラッグ&ドロップ。**
     変換して、できた JSON を `.minecraft/songs/` へ自動でコピーします。
     ```
     python3 tools/convert.py 曲.mp4                       ファイルが 1 つ
     python3 tools/convert.py 鍵盤の動画.mp4 元の動画.mp4    同じ曲の動画が 2 つ     (--no-install でコピーしない)
     ```
     - **ファイルが 1 つ**: ピアノロール動画(下に鍵盤があり、弾いた鍵が光る動画)は、映像から読みます(いちばん正確)。鍵盤が見つからない動画や、mp3 などの音声は、音声から推定します。mid は、そのまま読みます(ドラムも)。
     - **ファイルが 2 つ(同じ曲)**: 鍵盤のある動画を土台に、鍵盤のない動画(元の動画)の音を聞いて、細かく作ります(下の「2 つのファイルで作る」)。どちらに鍵盤があるかは、自動で見分けます。
     - 3 つ以上のファイルや、フォルダは受け付けません。
   - 動画だけを変換する `tools/video_to_notes.py`、音声・MIDI だけの `tools/audio_to_notes.py`、2 つで作る `tools/pair_to_notes.py` もあります。
   - ピアノロール動画は、鍵盤の位置・大きさを自動で検知します(88 鍵が全部映っていなくてもよい)。結果は、動画と同じフォルダに、動画と同じ名前の `曲.json` で出ます。オクターブは、`basic-pitch` が入っていれば音声と照らして確かめます。自動検知が合わないときだけ `--first-note F2 --x0 -2.6 --white-w 20.77 --white-y 332 --black-y 288` のように指定します。
   - 必要なものは、先に `tools/install_requirements.bat`(Windows)を実行すると入ります(手動なら下の 2 行)。ffmpeg も必要です(`winget install ffmpeg`)。動画だけを変換するなら、`python -m pip install --only-binary=:all: numpy` だけで動きます。
     ```
     python -m pip install --only-binary=:all: numpy scipy soundfile onnxruntime pretty_midi resampy librosa mir_eval
     python -m pip install --no-deps basic-pitch
     ```
     (`basic-pitch` をふつうに入れると、古い numpy をビルドしようとして失敗することがあります。`--no-deps` で、必要なものを別に入れます)
   - 音声からの推定: 主なオプションは `--start/--length`(秒)、`--max-poly`(同時発音数、標準12)、`--onset`、`--frame`、`--transpose`、`--speed`、`--drums`(音声から打楽器も探す。実験的)、`--no-harmonic-filter`(倍音の取り違えを取り除く処理を切る)。
     標準の設定は、映像から読んだ正解のある 2 曲(Yukopi・Soranji)と見比べて決めました。一致度(F1、時刻 ±0.1 秒・音程が同じ)は、Yukopi が 0.75 → 0.78、Soranji が 0.70 → 0.87 に上がっています。
2. 変換した JSON を `.minecraft/songs/` に入れ、`songmod-mc26.3.jar` を `mods/` に入れる(Fabric Loader / Fabric API が必要)。
3. 建てたい場所で建てたい方向を向いて `/song build 曲名`。日本語やスペースを含む名前は `"曲 名"` のように `"` で囲みます。始点のボタンを押すと演奏が始まります。

## コマンド
`/song list` / `/song build <名前> [折り返すマス数 | line]`(`line` で折り返しなしの 1 列) / `/song unforce`(チャンクの常時読み込みをやめる)

`/song build <名前> [折り返すマス数]`(省略時は JSON の row_length、それも無ければ自動。11〜201) / `/song stop` / `/song undo`(置いた分を元に戻す)

## 回路のしくみ
床に平らに並べます(前方向に一直線)。
```
幹:   ボタン → 石 → R(4) R(4) R(3) → 粉 → R(4) → 粉 → R(4) → 粉粉粉 → R(4) → …    (R = リピーター。幹はすべて最大の遅延 4)
枝:   幹の粉のマスから左右へ   粉 → R(遅延 d+1) → ブロック → 音符ブロック(前・手前・奥・上)
```
- **幹**: リピーターは最大の遅延 4(0.4 秒)で固定。リピーターのあいだは赤石粉 1 マスで、そこが分岐点です(幹の長さは、以前の約半分)。
- **枝**: 0.4 秒の区間の中の細かいずれ(0.1〜0.3 秒)は、枝のリピーターの遅延で合わせます。1 本の枝に音符ブロックを最大 4 個つけられます。
- **同時に鳴らす音が多いとき**: 同じ時刻の枝が足りなければ、幹の粉を 1 マスおきに連ねて、枝を増やします(粉は遅れがないので、同じ時刻のまま増やせる)。隣り合う枝は、短い枝(ブロックまで 3 マス)と長い枝(4 マス)を交互にして、音符ブロックがぶつかりません。
- **補強**: 粉は 15 マスまでしか信号を運べないので、枝が 14 本をこえるときは、途中に遅延 1 のリピーターを入れて信号を強め直します(そのぶん後ろの枝のリピーターの遅延を 1 引く)。1 つの時刻に、約 56 音までは補強なしで、ずれ d が 1 以上の音は、それ以上も置けます。
- **猶予**: ボタンを押してから最初の分岐点まで、リピーター 3 個(約 1.1 秒)あります。追従アイテムは、この間に最初の位置へなめらかに移動します。
- 音域で楽器が決まります(低:ベース、中:ハープ、高:ベル)。

## 音とチャンク
- 建てた回路の音符ブロックが鳴ると、40 ブロックより遠くにいるプレイヤーにも同じ音をそのまま聞かせます(近くでは本来の音)。
- 回路の範囲のチャンクは建てるときに常時読み込みにします(離れても演奏が止まらない)。不要になったら `/song undo` か `/song unforce`。

## アイテム
`/song item` で受け取れます(クリエイティブのタブ「曲づくり」にもあります)。
- **曲の追従**: 右クリックで ON / OFF。ON のあいだ、曲を流すと再生位置へなめらかに移動します。
- **休符**: 曲が流れているときに右クリックすると、いま鳴っている場所の前後のリピーターを壊して曲を止め、1 秒後にリピーターを元へ戻します(戻しても続きは流れません。もう一度ボタンを押すと最初から)。

## 2 つのファイルで作る(鍵盤の動画 + 元の動画)
```
python3 tools/convert.py 鍵盤の動画.mp4 元の動画.mp4
```
1. 鍵盤の動画から、弾かれた音(音程・長さ)を読み取ります。ここが土台です。
2. 元の動画の音を聞いて、**時刻を合わせます**。音符の「和音の並び」と、元の音声の和音を照らして、時間のずれ・テンポの違いを求めます(直線と、場所ごとの対応の 2 通りを試して、よく合うほうを選びます)。
3. 近くの音符たちをまとめて、元の音声の同じ音程の出だしに合わせて、**タイミングを細かく直します**。
4. 元の音声から、**ドラム**(バスドラム・ハイハット)を探して足します(`--snare` でスネアも。誤検出が多いので標準は入れません。`--no-drums` で足さない)。
- 結果は、元の動画の名前で、元の動画と同じフォルダに出ます。
- 合成した「元の動画」(テンポを変えて、ドラムを混ぜたもの)で試したところ、音符の時刻は、音声の本当の出だしと **0.1 秒以内に約 98%、0.05 秒以内に約 95%** 合いました(出だしを確認できた音符は約 93%)。実際の曲(ボーカルやバンドの音が混ざったもの)では、これより下がります。
- 元の音声に無い音符を足したり、元の音声で聞こえない音符を消したりはしません(鍵盤の動画のとおりです)。

## 音量(音ごとの強さ)
- JSON の音符は `[時刻, 音程, 強さ]` の形で、**強さ(1〜100 %)**を持てます(省略すると 100 %)。変換ツールが、元の音声の大きさから求めます(元の曲で小さく弾いている音は、小さい値になる)。MIDI は、ベロシティから求めます。2 つのファイルで作るときは、元の動画の音から求めます。鍵盤の動画だけのときは、その動画の音から求めます(音声が無い動画は、すべて 100 %)。
- ゲームの中では、音符ブロックの上に**見えないブロック(光のブロック)**を置いて、音符ブロック本来の(固定の大きさの)音を出さないようにして、かわりに、このMODが、**聞く人ごとに距離で小さくして**聞かせます。
  - 音量 = 音符ごとの強さ × 全体の音量 × **楽器・音域の補正** × (1 − 距離 / 100 ブロック)。距離が 0 で 100 %、**100 ブロックで 0 %(それより遠くは聞こえません)**、その間は直線で小さくなります。バニラの音符ブロックの範囲(48 ブロック)より広くしてあります。
  - 距離の帯は、0〜20 ブロックが 80〜100 %、20〜40 が 60〜80 %、40〜60 が 40〜60 %、60〜80 が 20〜40 %、80〜100 が 0〜20 % です。
  - 音の方向は、本来の位置のとおりです(左右に広がって聞こえる)。**追従アイテム**を使うと、いま鳴っている場所から 10 ブロック以内(80〜100 % の帯の中)に聞く人を保つので、いちばん大きく聞こえます。
- **楽器・音域の補正:** 音符ブロックの音は、楽器によって、もとの大きさが約 20 dB も違います(実測: ベースは −42〜−33 dB、ハープは −34〜−30 dB、ベルは −32〜−29 dB、フルートは −24 dB、カウベルは −22 dB)。そこで、Minecraft 本体の音(note/*.ogg)を実際に測って、大きい音を、基準の大きさ(−34 dB)まで下げる補正を入れてあります(小さい音は、音量 1 が上限で持ち上げられないので、そのまま)。表は `tools/measure_note_sounds.py` で作り直せます。
- 選曲台の一覧画面の「全体の音量」ボタン(100 / 75 / 50 / 25 / 10 %)で、全体の音量を変えられます(建てた回路にも、すぐ反映されます)。
- 音の種類ごとの音量は、Minecraft の設定の「音楽とジュークボックス」のスライダーでも変えられます。
- 以前の「どこにいても同じ大きさで聞こえる」は、なくなりました(100 ブロックより遠いと聞こえません)。

## 打楽器
JSON の音符は `[時刻, 音程]` のほか、`[時刻, 0, "basedrum"]`(バスドラム)・`"snare"`(スネア)・`"hat"`(ハイハット)の形で、打楽器も書けます(楽器の名前と強さは、どちらの順でも書けます: `[時刻, 0, "snare", 80]`)。MIDI のドラムトラックは、自動でこの形に変換されます(キック・タム → バスドラム、スネア・クラップ → スネア、ハイハット・シンバル → ハイハット)。音符ブロックの土台は、石・砂・ガラスです。

## 見た目
- 鳴った音符ブロックは、一瞬きらっと光ります(近くの人に見える)。

## 選曲台(ブロック)
`/song item` で受け取れます(クリエイティブのタブ「曲づくり」にもあります)。置くと、置いた人のほうを向き、上にボタンが付きます。
- 右クリックで曲の一覧画面が開き、クリックで曲を選びます(`.minecraft/songs/` の曲が並びます。多いときはページ送り)。選んだ曲名は、台の手前に浮かぶ文字で見えます。
- 上のボタンを押すと、選んだ曲の回路が台の後ろ側に建ちます(折り返さない 1 列(`line`)で、台の後ろ側へまっすぐ伸びます。曲の JSON の `row_length` に関係なく 1 列です)。
- 同じ台(または同じプレイヤーの `/song build`)でもう一度建てるときは、前に建てた回路を先に消します。床の層(滑らかな石・音符ブロックの土台・砂の支え)は、**すべて草ブロック**になります。それより上は、ゲームを再起動していなければ元の地形に戻し、再起動したあとは空気になります。
- 一覧画面の「この台で建てた回路を消す」で、その台が建てた回路を消せます。
- 一覧画面の下の「⏮ 頭から」「−30秒」「+30秒」「⏸ 一時停止 / ▶ 再開」で、再生位置を操作できます(その台が建てた回路に対して)。画面の上に、再生位置が出ます。流れている途中で動かすと、休符と同じように信号を 1 秒止めてから、指定した位置の幹のリピーターへ信号を入れ直します。
- 一覧画面の「速度」「移調」「音色」は、押すたびに次の値になります(次に建てるときから反映)。速度は 50〜200%、移調は −12〜+12 半音、音色は「自動」のほか、ハープ・ギター・ベル・フルート・シロフォン・鉄琴・ピコピコ・バンジョーから選べます(音程のある音がすべてその楽器になり、音域は 2 オクターブに折りたたまれます。打楽器はそのまま)。
- 台を壊すと、曲名の文字も消えます(回路は残ります)。

## 制限
- 時間の細かさはリピーター 1 目盛り = 0.1 秒。
- 同時に鳴らせる数は、変換時の上限(標準 12 音)まで。回路側は、1 つの時刻に約 56 音まで置けて、それをこえる分は省かれます(ふつうの曲では起きません)。
- 回路は折り返さず、一直線に伸びます(`row_length` や `/song build` の折り返しの指定は、いまは使われません)。
- 音域は F#1〜F#7。範囲外は 1 オクターブずつ折り返します。
- 長い曲は回路が大きくなります(1 分 ≒ 数十×数十マス)。
- ドラムなどの打楽器音は音程として読むため、そのままは再現できません。
