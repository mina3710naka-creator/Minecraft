# 魔法MOD(magicmod)

`design/魔法MOD_詳細設計書.md.html`(v5)と `design/魔法MOD_数値バランス_v3.xlsx` をもとに作った Fabric MOD です(Minecraft 26.3)。
魔法の本・杖・魔法テーブル・装備・スキルツリー・物理わざ・アーキタイプ・使い魔・刻印・魔法合成・武器合体・属性の敵とボスが入っています。

## 入れ方
`magicmod/dist/magicmod-mc26.3.jar` を `.minecraft/mods/` に入れます(Fabric Loader と Fabric API が必要)。
初めてワールドに入ると「魔法の手引き」がもらえます(右クリックで遊び方・属性相性・敵図鑑)。

## 操作(キーはオプションで変更可)
| キー | 内容 |
| --- | --- |
| 右クリック / `R` | 杖(魔法剣)で選んでいる魔法を撃つ |
| `Z` / `X` | 前の魔法 / 次の魔法 |
| `G` / `V` | 物理わざを使う / わざを切り替える(武器を持って) |
| `H` | 使い魔を召喚 / 送還 |
| `K` | ステータス画面(刻印・装備・使い魔・スキルツリー) |
| 左クリック(魔法型・杖) | 魔封じの型(MP・CT 消費なしの基本攻撃。当たると MP 回復) |
| 空中でジャンプ | エアステップ中の二段ジャンプ |

画面左上に MP・スタミナ・選択中の魔法とわざ・クールタイム・オーバーヒート・使い魔が出ます。

## 遊び方の流れ
1. **水晶鉱石**(Y80 以下)を掘って水晶欠片、**銀鉱石**から銀。水晶欠片+素材で各属性の結晶、結晶+本で**魔法書**、水晶欠片+棒で**木の杖**。
2. **選定の祭壇**でアーキタイプ(物理型 / 魔法型 / 均衡型)を選ぶ。最初は無料、選び直しは「転身の宝珠」。
3. **魔法テーブル**(本や杖を持って右クリック)
   - 獲得: 素材で魔法を習得 / 装着: 持っている本のスロットに魔法を入れる / 強化: +6%/Lv
   - 本に捧げる: 素材を本の EXP に / 杖の本: 本を杖にセット(1 番目の本の属性がエレメンタル・魔封じの型の属性)
   - エンチャント: 杖(魔力強化・消費魔力軽減・効果時間延長・詠唱短縮・スロット拡張・CT短縮)と装備
   - 合成炉: ベースの形+サブの状態異常で合成魔法の巻物を作る(失敗なし・プレビューと相性ヒント★あり・本の 2 枠を使う)/ 図鑑: 固定レシピと既知レシピ
4. **鍛冶テーブル**(武器を持って): 物理わざの習得・装着(熟練度でスロットが増える)、武器エンチャント、**武器合体**(メインに近接武器・オフハンドに杖で魔法剣)
5. **召喚祭壇**で使い魔契約書、**秘術の祭壇**で刻印、**封印の祭壇**で中ボス・属性超越ボスを呼び出す。
6. 帽子・ペンダント・手袋・腕輪は右クリックで装備。物理型・魔法型の固有装備は均衡型なら両方付けられる。

## 入っているもの
- **魔法 104 種**(8 属性 × 13)。名前・状態異常・MP・CT・ダメージ係数は数値バランス表のとおり。本 Lv1〜2 で ①〜④、Lv3 で ⑤〜⑦・⑪〜⑬、Lv4 で ⑧〜⑩。最大魔法 ⑩ はボスの属性核石+共通触媒が必要で、Lv4 以上の本がないと習得できない。
- **物理わざ 63 種**(直剣/斧/鈍器・長柄・双数・振り回し・投擲・弓・大型 × 9)。バニラの剣・斧・メイス・槍・トライデント・弓・クロスボウも対象。MOD の武器 14 種(ロングソード・双剣・フレイル・クサリ鎌・投げナイフ・ブーメラン・大剣 など)。
- **MP 経済**: 自然回復は遅く、近接ヒットで回復(魔法剣は 2 倍)。同じ魔法・属性の連発でオーバーヒート。闘志の刻印で「殴って溜めて撃つ」。
- **アーキタイプ**: 物理型(わざ +30%・魔法 CT 2 倍・MP -30%)/ 魔法型(魔法 +30%・CT -30%・魔封じの型)/ 均衡型(補正なし・両系統の固有装備)。使い魔・刻印にも ±10% の補正。
- **使い魔 10 種**(ウルフ〜エンシェントドラゴン)。維持 MP、レベル、エレメンタルは杖の 1 番目の本の属性で攻撃、フェニックスは死亡時に 1 度だけ蘇生。
- **刻印 10 種**(常時発動、戦闘中の付け替えは 60 秒 CT、覇者の刻印は単独専用)。
- **状態異常**: 出血・火傷・感電・麻痺・気絶・拘束・転倒・溺れ・恐怖・混乱・命中率低下・防御力低下・詠唱不可・MP回復不可・ドゥームカースなど。
- **属性相性**(設計書 11.1)と敵の弱点 ×1.5・同属性 ×0.5、光はアンデッドに 2 倍(最大魔法 3 倍)、呪いの合成親和性(11.4)。
- **敵 32 種**: 雑魚 16(自然にスポーン)、中ボス 8、属性超越ボス 8(封印の祭壇。ボスバー・第 2 形態・同属性免疫)。HP・防御係数は表の値(1024 を超える HP は被ダメージ倍率で再現)。
- **スキルツリー**: 属性別(火力/支援/持続)× 8、共通(MP・詠唱・合成・CT・本EXP・刻印枠・契約枠)、物理(カテゴリ特化・スタミナ・コンボ・わざ枠)。

## 戦い方(回避・コンボ・元素反応・ボスの予兆)
- **回避ステップ**(既定は左 Alt、スタミナ20): 向いている方向(押している移動キーの向き、無ければ後ろ)へ素早く動き、0.5 秒だけ無敵。
  - 無敵の間に攻撃が来ていたら**ジャスト回避**: スタミナが返り、MPが 15 回復し、3 秒間 威力 +25%。
- **コンボ**: 魔法・物理わざ・近接・元素反応を当て続けると数が増える(物理と魔法を交互につなぐと +1)。10/25/50/100 で威力 +5/10/15/25%。4 秒つながらない、または被弾すると途切れる。
- **元素反応**: 魔法を当てると敵に属性の「しるし」が付き、6 秒以内に別の属性を当てると反応(同じ相手には 1.5 秒あける、反応でコンボ+3)。
  - 炎+水=蒸発 / 雷+水=拡散感電 / 風+炎=火炎旋風 / 重力+雷=磁力爆縮 / 光+闇=対消滅 / 呪い+闇=侵食 / 風+水=凍結 / 炎+雷=過負荷 / 風+雷=雷嵐 / 重力+水=渦潮
- **予兆つきの攻撃**: 中ボス 8 体・ボス 8 体と一部の雑魚が、地面に赤い危険範囲を出してから攻撃する(円・ドーナツ・直線・十字・連続落下・突進)。範囲が満ちた瞬間に当たる。第 2 形態は予兆が 2 割短い。長さは settings.json の `telegraphTimeMultiplier` で変えられる。
- 設定: `config/magicmod/settings.json`(難易度・ボスHP倍率・ダメージ倍率・PvP・地形変化・予兆の長さ など。`/magic settings reload` で反映)。
- 使い魔は、ログインし直し・復活・次元移動のあとに自動で戻る。

## 見た目と操作(アイコン・ホイール・効果音)
- **魔法ホイール**(`B` を押している間): 杖の魔法がアイコンの輪で出て、マウスを向けてキーを離すと切り替わる。魔法が多いと内側と外側の2重の輪になる。
- **アイコン**: 魔法104種と物理わざ7カテゴリに専用のアイコン(属性色の板+図柄+ランクの枠)。魔法テーブル・鍛冶テーブル・HUD・ホイールで使う。
- **効果音**: 属性ごとの詠唱音と着弾音(8属性)、最大魔法の溜めと解放、予兆、回避、ジャスト回避、元素反応、コンボ、ボスの咆哮。`tools/gen_sounds.py` で合成した音。
- **色分け**: 中ボス・ボス・使い魔は、属性の色で輪郭が光る(炎=赤、雷=黄、水=水色 など)。

## 演出
- **MOD 独自の演出**(すべて自前の絵):
  - 属性ごとの**大きな魔法陣**(炎=六芒星と炎、雷=八芒星と稲妻、水=波紋と雫、風=渦、重力=重なる正方形と特異点、闇=逆五芒星と眼、光=光輪と太陽、呪い=五芒星と髑髏)が詠唱中・範囲魔法・ボス登場で地面に広がって回る
  - 地面を走る**衝撃波の輪**、振り抜く**三日月の斬撃**(属性色・武器は鋼色)、**光の柱**、**稲妻**、**特異点の黒い球**
  - 独自パーティクル 10 種: 火の粉・電光・水滴・風刃・虚空の粒・影の霧・聖なる星・呪いの髑髏・ルーン文字・鋼の閃き
- **詠唱**: 中位以上は足元に回転する魔法陣が広がり、光が手元に集まる。最大魔法は光の筋が放射される。
- **魔法弾**: 光る大きめの結晶が飛び、属性ごとの尾を引く(炎=火の粉と煙と溶岩、雷=ジグザグの放電、水=泡としぶき、風=渦巻く雲、重力=吸い込む粒、闇=墨と煙、光=光の粒、呪い=魂)。着弾で閃光と破片。
- **範囲・光線・斬撃**: 広がる衝撃波と地面の破片、螺旋を巻く光線、武器と近接魔法は弧を描く斬撃。
- **持続範囲**: 風=竜巻、雷=走る放電、炎=燃える床、水=渦潮、重力=特異点、闇・光・呪い=回る魔法陣。
- **最大魔法**は専用の演出(連続落雷からの巨大な一撃、竜の息、押し寄せる大波、育って潰れる特異点、深淵の門、天からの光の柱、呪印)。
- **画面の揺れと閃光**(大技・ボス)、**浮かぶダメージ数値**(弱点は「弱点!」、回復は緑。ステータス画面でOFF可)。
- **状態異常が見える**: 出血のしずく、感電の放電、気絶の星、拘束の輪、溺れの泡、ドゥームの呪印とカウントダウン など。
- **敵のオーラ**、**中ボス・ボスの登場タイトル/第2形態の咆哮と衝撃波/討伐の爆発と光の柱**。
- **地形への反応**: 水魔法は火を消し溶岩を黒曜石に、凍結は水面を薄氷に(時間で溶ける)、炎は雪と氷を溶かす。炎の大技が地面に火をつけるのは `mobGriefing` が有効なときだけ。
- 村人・行商人・ペット・使い魔・プレイヤーが作ったゴーレムには魔法もわざも当たらない(それ以外の生き物には範囲攻撃も当たる)。

見た目について: 敵と使い魔はバニラのモデルを流用し、大きさ(SCALE)と名前・パーティクルで区別しています。アイテムのテクスチャは `tools/gen_assets.py` が描いたドット絵です。

## 遺跡・最終ボス・融合魔法・物理モーション

- **属性の遺跡(8 種)**: 属性ごとの地形(砂漠/丘/平原/海辺/山/暗い森/花畑/沼)に、封印の祭壇・宝箱・守護の手下がいる遺跡が自然生成されます。`/magic ruin <属性>` で目の前に建てられます。
- **最終ボス「万象の魔王オムニス」**: 8 体の属性超越ボスをすべて倒すと封印の祭壇に現れる挑戦枠。5 秒ごとに属性が切り替わり、その属性は無効・対になる属性が弱点になります。倒すと「魔王の心臓」などを入手。
- **融合魔法(28 種)**: 最大魔法どうし(ベース+サブ)を属性違いで合成すると、「○○式」ではなく組み合わせ専用の新魔法になります(例: 風×雷=ストームクラウン、重力×闇=イベントホライズン、闇×光=トワイライトエクリプス)。一覧は鍛冶テーブルの「レシピ」タブ。
- **物理モーション**: 剣/長柄/双剣/振り回し/大型武器は、連続で当てると 4 段で技が変化します(例: 剣 = 横薙ぎ→逆袈裟→切り上げ→回転斬り)。4 段目は必ずフィニッシャー。間が空くと 1 段目に戻ります。
- **独自の 3D モデル**: 敵 33 種・使い魔 8 種(ボスとオムニスを含む 41 種)は、バニラの見た目の借り物ではなく専用の形とテクスチャを持ちます(`tools/gen_models.py` で生成)。目や核は暗い所でも光り、歩行・羽ばたき・浮遊・尻尾・周回する石や輪などが動きます。
- **武器の振り**: 武器の種類ごとに振りの型と速さが違います(槍=突き、双剣=素早い、大型=大振り)。連携の段が進むと、二段突き・X字・フィニッシュの大振りなど振り直しが入ります。
- **効果音**: 武器の振り・命中・フィニッシャー、敵と使い魔の鳴き声(8 種類 × 通常・被弾・撃破)を追加。独自の敵はバニラの鳴き声ではなくこちらが鳴ります。
- **使い魔の進化**: 使い魔は Lv に応じて 4 段階(Lv1-2 / 3-5 / 6-9 / 10)で見た目が変わります(首輪→鎧板→角と光る尾→周回する光など)。体も少しずつ大きくなります。
- **使い魔は同時に 1 体だけ**: 契約が複数ある場合は、[H] を押しながらマウスホイールで召喚する使い魔を選べます(出しているときは、その場で入れ替わります)。[H] を軽く押すと召喚/送還です。スピリットウルフも 1 体です。
- **乗れる使い魔**: スピリットウルフ・ゴーレム(地上)、フェニックス・エンシェントドラゴン(飛行)。Lv3 以上で、右クリックで騎乗。WASD で移動、ジャンプで跳ぶ(飛行型は視線の向きに飛び、ジャンプで上昇)、しゃがみで降ります。
- **三重融合魔法(56 種)**: 最大魔法 3 つ(ベース+サブ 2、すべて違う属性)を合成すると、組み合わせごとの固有魔法になります。3 属性から 2 つずつ取った融合魔法を三連で放ち、最後に 3 属性が収束して炸裂します。
- **騎乗中の右クリック = 専用攻撃**: スピリットウルフ=疾風の突進、ゴーレム=地割れ(予兆つきの範囲攻撃・転倒)、フェニックス=火炎の放射、エンシェントドラゴン=ブレス(使うたびに属性が替わる)。使い魔の攻撃力と Lv で威力が上がります。
- **えさやり**: 使い魔に好物を持って右クリック(例: ウルフ=肉類、フェアリー=はちみつ・ベリー、ゴーレム=鉄・銅・石炭、ドラゴン=エンダーパール・コーラスフルーツ・ダイヤ)。Lv5 まではえさで育ちます(1 個で +40、Lv5 = 経験値 400)。それ以降は 1 個で +2 だけ。名前と見た目はその場で進化します。しゃがみ+右クリックすると、Lv・経験値・好物を確認できます。
- **新しい騎乗使い魔**: ペガサス(空を駆ける・乗って右クリックで光の突撃・近くの持ち主の落下を和らげる)とベヒーモス(大地を駆ける巨獣・右クリックで突進して敵を転倒させる・近くの持ち主の防御を高める)。召喚祭壇で契約書を作ります。
- **ギルド**: 「ギルド掲示板」(クラフト可)を右クリックすると、毎日 4 件の依頼(属性の敵の討伐・中ボス以上の討伐・素材の納品・敵の討伐)が出ます。同時に 3 件まで受けられ、達成すると素材・使い魔のえさ・スキルポイントがもらえます。5 件達成するごとにギルドランクが上がり、報酬が増えます。
- **生活魔法**: 「生活の魔導書」(クラフト可)。しゃがみ+右クリックで切り替え、右クリックで使います(MP 消費)。成長(周囲の作物・草木を育てる)/収穫(実った作物を刈り取り植え直す)/灯火(松明を置く)/浄化(状態異常と火を消す)/採掘補助(つながった鉱石をまとめて掘る)。
- **使い魔のスキル([J])**: 乗れない使い魔にも専用スキルがあります(クールタイム 30 秒から、使い魔の Lv で短くなる)。ウルフ=咆哮(味方を加速・強化、敵は恐怖)、マッドスライム=粘液の壁(敵を鈍足に・自分に吸収)、フェアリー=癒しの光(範囲回復・状態異常解除)、ホーク=鷹の目(広範囲の敵を発光・暗視)、ガーディアン=守護の結界(味方に吸収と防御)、エレメンタル=属性の大爆発(装着中の本の属性)。乗れる使い魔は騎乗中の右クリックが専用攻撃です。
- **進化の儀式**: 使い魔が進化する Lv3・6・10 に、光の柱・魔法陣・タイトル表示の演出が出ます。
- **ギルドの小屋と受付**: 平原・森・タイガ・サバンナなどに「ギルドの小屋」(掲示板・本棚・樽つき)が自然に生成され、中の受付(村人)を右クリックでギルド画面が開きます(`/magic guildhall` でも建てられます)。ギルドランクに称号(見習い冒険者→冒険者→熟練の冒険者→英雄→伝説の冒険者)がつき、ランク 3 からボス討伐の「特別依頼」(報酬: SP 2・核石・エッセンス)が出ます。1 日 4 件すべて達成するとボーナスがもらえます。
- **生活魔法の拡張**: モードに「繁殖」(近くの動物を繁殖状態に)・「整地」(上の自然物を取り除きへこみを土で埋める)・「調理」(持ち物の生肉・魚・イモを焼く)を追加。使うほど「生活の熟練度」(Lv1〜10)が育ち、範囲・採掘上限が広がり、MP が少し安くなります。
- **融合魔法の威力調整**: 二重融合は元の最大魔法の 3 倍、三重融合は 3.6 倍の威力係数にしました(測定で、調整前は元の最大魔法より弱かったため)。三重融合の締めは 8 種類の形(柱の輪・流星雨・螺旋・十字の光線・ドーム・渦・雷の網・陽光)のどれかで、3 属性の色になります。開発用に `/magic fusiontest` で威力を測れます。
- **使い魔のオーラ**: 進化段階 2 以上の使い魔は、種類ごとのオーラをまといます(ウルフ=青い炎、フェニックス=炎、ドラゴン=属性が巡る火花、ペガサス=光の粒、ゴーレム=火花など)。段階が上がるほど濃くなります。
- **新しい効果音**: 進化、使い魔スキル、依頼の受注・完了、生活魔法、騎乗の突進、融合魔法のチャージ、三重融合の締め。
- **ウルフ系の強化**: ウルフとスピリットウルフは前線の主力になりました(体力 ×2.4・攻撃 ×2.6・足が速い・ノックバックに強い)。噛みつくと出血が重なり、進化で戦い方が変わります — 段階2=飛びかかりと追加の噛み傷・自然回復、段階3=爪の3連撃・体力吸収・持ち主に攻撃力アップ、段階4=ファントムファング(四方からの霊体の牙)。見た目もたてがみの炎・肩のとげ・脚の刃・霊体の尾・背の炎とより迫力を出し、大きさは約 2 倍。
- **攻撃モーション**: 使い魔と敵の独自モデルは、攻撃するときに体ごと踏み込み、頭が噛みつき、前脚・腕が振り下ろされ、翼が打ち、尾が払われます(使い魔の能力・スキル・騎乗攻撃でも動きます)。
- **物理武器の実モーション**: 剣・長柄・双剣・振り回し・大型武器は、一人称の手元と三人称の腕が、武器の種類 × 連携の段(1〜4)ごとに別々のキーフレームの動きをします(剣=横薙ぎ→逆袈裟→切り上げ→回転斬り、槍=突き→二段突き→薙ぎ払い→突進、大型=高く振りかぶって叩きつける、など)。
- **使い魔のレベルと強さ**: Lv1 はかなり弱く(性能 ×0.45)、Lv5 でゾンビ数体を倒せる水準(×1.0)。Lv6 以降は 1 レベルに必要な経験値が増えます(累積 550 / 770 / 1070 / 1470 / 1990)が、性能は大きく伸び、Lv10 で約 ×6.2(ゴーレムを一撃・ウォーデンにも勝てる)。ウルフ以外の使い魔も全体に底上げ(体力 ×1.5・攻撃 ×1.6)。
- **ウルフに乗れる**: ウルフ(Lv3〜)にも右クリックで騎乗でき、騎乗中の右クリックで突進攻撃。
- **エンシェントドラゴンを作り直し**: 約 1.4 倍に大きくし、胸・腹・腰の胴、S 字の長い首、角と牙のある頭、指の骨と膜の翼(上腕・前腕・指 4 本)、太い後脚、とげだらけの長い尾の、ドラゴンらしい姿に(強さは変えていません)。全体を黒ベース(赤い筋と琥珀色の光る目)にし、顔は光る目・重ねたまゆ・額のとさか・鼻の張り出しと光る鼻孔・犬歯と歯の列・あごひげ・ほおの鱗板・広い耳のひれ・首の後ろのえりまで作り込みました。

- **飛ぶ使い魔の動き**: ドラゴンとペガサスは、足をばたつかせず(畳んだまま)首も振らず、ゆっくり大きく翼をはばたかせ、加減速しながらなめらかに飛びます。

## 数値の調整
- `tools/gen_data.py` が xlsx から `src/main/resources/magicmod/balance.json` を作ります。xlsx を直したら
  `python3 -I tools/gen_data.py design/魔法MOD_数値バランス_v3.xlsx src/main/resources/magicmod/balance.json` を実行してビルドし直します。
- jar を作り直さずに試すなら、`balance.json` を `.minecraft/config/magicmod/balance.json` に置いて書き換えると、そちらが優先されます。
- 計算順序は `Calc.java` の先頭にまとめてあります。

## 管理者コマンド(OP)
`/magic kit`(星屑の杖・Lv5 の本 8 冊・テーブルと祭壇)、`/magic learnall`、`/magic archetype <physical|magic|balanced>`、`/magic sp <数>`、`/magic mastery <EXP>`、`/magic fill`(MP・スタミナ・CT 回復)、`/magic ui <画面>`、`/magic cast`、`/magic act <番号>`(近くの敵の技を出す)、`/magic loadout <属性> <番号>`、`/magic settings`、`/magic reset`、`/magic selftest`(全魔法・全わざ・画面を偽プレイヤーで動かして例外が出ないか確認)。

`.github/workflows/build-magicmod.yml`(手動実行で jar を `magicmod/dist/` に保存)。ローカルでは JDK 25 と Gradle で `gradle build`。
