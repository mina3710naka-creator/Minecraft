# 魔法MOD(magicmod)

`design/魔法MOD_詳細設計書.md.html`(v5)と `design/魔法MOD_数値バランス_v3.xlsx` をもとに作った Fabric MOD です(Minecraft 26.3)。
魔法の本・杖・魔法テーブル・装備・スキルツリー・物理わざ・アーキタイプ・使い魔・刻印・魔法合成・武器合体・属性の敵とボスが入っています。

## 入れ方
`magicmod/dist/magicmod-mc26.3.jar` を `.minecraft/mods/` に入れます(Fabric Loader と Fabric API が必要)。
初めてワールドに入ると「魔法の手引き」がもらえます(右クリックで遊び方・属性相性・敵図鑑)。

## 操作(キーはオプションで変更可)
| キー | 内容 |
| --- | --- |
| 右クリック / `R` | 杖(魔法剣)で選んでいる魔法を撃つ |
| `Z` / `X` | 前の魔法 / 次の魔法 |
| `G` / `V` | 物理わざを使う / わざを切り替える(武器を持って) |
| `H` | 使い魔を召喚 / 送還 |
| `K` | ステータス画面(刻印・装備・使い魔・スキルツリー) |
| 左クリック(魔法型・杖) | 魔封じの型(MP・CT 消費なしの基本攻撃。当たると MP 回復) |
| 空中でジャンプ | エアステップ中の二段ジャンプ |

画面左上に MP・スタミナ・選択中の魔法とわざ・クールタイム・オーバーヒート・使い魔が出ます。

## 遊び方の流れ
1. **水晶鉱石**(Y80 以下)を掘って水晶欠片、**銀鉱石**から銀。水晶欠片+素材で各属性の結晶、結晶+本で**魔法書**、水晶欠片+棒で**木の杖**。
2. **選定の祭壇**でアーキタイプ(物理型 / 魔法型 / 均衡型)を選ぶ。最初は無料、選び直しは「転身の宝珠」。
3. **魔法テーブル**(本や杖を持って右クリック)
   - 獲得: 素材で魔法を習得 / 装着: 持っている本のスロットに魔法を入れる / 強化: +6%/Lv
   - 本に捧げる: 素材を本の EXP に / 杖の本: 本を杖にセット(1 番目の本の属性がエレメンタル・魔封じの型の属性)
   - エンチャント: 杖(魔力強化・消費魔力軽減・効果時間延長・詠唱短縮・スロット拡張・CT短縮)と装備
   - 合成炉: ベースの形+サブの状態異常で合成魔法の巻物を作る(失敗なし・プレビューと相性ヒント★あり・本の 2 枠を使う)/ 図鑑: 固定レシピと既知レシピ
4. **鍛冶テーブル**(武器を持って): 物理わざの習得・装着(熟練度でスロットが増える)、武器エンチャント、**武器合体**(メインに近接武器・オフハンドに杖で魔法剣)
5. **召喚祭壇**で使い魔契約書、**秘術の祭壇**で刻印、**封印の祭壇**で中ボス・属性超越ボスを呼び出す。
6. 帽子・ペンダント・手袋・腕輪は右クリックで装備。物理型・魔法型の固有装備は均衡型なら両方付けられる。

## 入っているもの
- **魔法 104 種**(8 属性 × 13)。名前・状態異常・MP・CT・ダメージ係数は数値バランス表のとおり。本 Lv1〜2 で ①〜④、Lv3 で ⑤〜⑦・⑪〜⑬、Lv4 で ⑧〜⑩。最大魔法 ⑩ はボスの属性核石+共通触媒が必要で、Lv4 以上の本がないと習得できない。
- **物理わざ 63 種**(直剣/斧/鈍器・長柄・双数・振り回し・投擲・弓・大型 × 9)。バニラの剣・斧・メイス・槍・トライデント・弓・クロスボウも対象。MOD の武器 14 種(ロングソード・双剣・フレイル・クサリ鎌・投げナイフ・ブーメラン・大剣 など)。
- **MP 経済**: 自然回復は遅く、近接ヒットで回復(魔法剣は 2 倍)。同じ魔法・属性の連発でオーバーヒート。闘志の刻印で「殴って溜めて撃つ」。
- **アーキタイプ**: 物理型(わざ +30%・魔法 CT 2 倍・MP -30%)/ 魔法型(魔法 +30%・CT -30%・魔封じの型)/ 均衡型(補正なし・両系統の固有装備)。使い魔・刻印にも ±10% の補正。
- **使い魔 10 種**(ウルフ〜エンシェントドラゴン)。維持 MP、レベル、エレメンタルは杖の 1 番目の本の属性で攻撃、フェニックスは死亡時に 1 度だけ蘇生。
- **刻印 10 種**(常時発動、戦闘中の付け替えは 60 秒 CT、覇者の刻印は単独専用)。
- **状態異常**: 出血・火傷・感電・麻痺・気絶・拘束・転倒・溺れ・恐怖・混乱・命中率低下・防御力低下・詠唱不可・MP回復不可・ドゥームカースなど。
- **属性相性**(設計書 11.1)と敵の弱点 ×1.5・同属性 ×0.5、光はアンデッドに 2 倍(最大魔法 3 倍)、呪いの合成親和性(11.4)。
- **敵 32 種**: 雑魚 16(自然にスポーン)、中ボス 8、属性超越ボス 8(封印の祭壇。ボスバー・第 2 形態・同属性免疫)。HP・防御係数は表の値(1024 を超える HP は被ダメージ倍率で再現)。
- **スキルツリー**: 属性別(火力/支援/持続)× 8、共通(MP・詠唱・合成・CT・本EXP・刻印枠・契約枠)、物理(カテゴリ特化・スタミナ・コンボ・わざ枠)。

見た目について: 敵と使い魔はバニラのモデルを流用し、大きさ(SCALE)と名前・パーティクルで区別しています。アイテムのテクスチャは `tools/gen_assets.py` が描いたドット絵です。

## 数値の調整
- `tools/gen_data.py` が xlsx から `src/main/resources/magicmod/balance.json` を作ります。xlsx を直したら
  `python3 -I tools/gen_data.py design/魔法MOD_数値バランス_v3.xlsx src/main/resources/magicmod/balance.json` を実行してビルドし直します。
- jar を作り直さずに試すなら、`balance.json` を `.minecraft/config/magicmod/balance.json` に置いて書き換えると、そちらが優先されます。
- 計算順序は `Calc.java` の先頭にまとめてあります。

## 管理者コマンド(OP)
`/magic kit`(星屑の杖・Lv5 の本 8 冊・テーブルと祭壇)、`/magic learnall`、`/magic archetype <physical|magic|balanced>`、`/magic sp <数>`、`/magic mastery <EXP>`、`/magic fill`(MP・スタミナ・CT 回復)、`/magic ui <画面>`、`/magic cast`、`/magic reset`、`/magic selftest`(全魔法・全わざ・画面を偽プレイヤーで動かして例外が出ないか確認)。

## ビルド
`.github/workflows/build-magicmod.yml`(手動実行で jar を `magicmod/dist/` に保存)。ローカルでは JDK 25 と Gradle で `gradle build`。
アセットを作り直すときは `python3 -I tools/gen_assets.py`。
