# recmod(Rec Mod)

Minecraft(Fabric)用の、クライアント専用 MOD。メニューの「録画」ボタンで、**プレイヤーの視点を、音つきで録画**する。停止すると、ダウンロードフォルダーに保存される。

## 使い方

1. Esc でメニューを開く。左上に **「● 録画」** ボタンがある。押すと録画が始まる(チャットに知らせが出る)。
2. 録画中は、画面の左上に赤い「● REC 0:12」が出る。メニュー(Esc)を開くと、ボタンが **「■ 停止 0:12」** に変わっている。
3. 「■ 停止」を押すと、保存する。チャットに、保存した場所(クリックで開ける)が出る。
   - 保存先: ユーザーフォルダーの `Downloads`(なければ、ゲームのフォルダーの `recordings/`)
   - ファイル名: `minecraft-20260101-120000.mp4`
4. 世界から出たとき、ゲームを終えたときも、録画中なら自動で止めて保存する。

## 録音(音だけ)

Esc メニューの左上、「● 録画」の下に **「♪ 録音」** ボタンがある。押すとゲームの音だけを録音し、「■ 録音停止」を押すと、`minecraft-audio-日時.m4a`(AAC)を、録画と同じフォルダーに保存する。映像は取らないので、ゲームへの負荷はほとんどない。録画中は録音できず、録音中は録画できない(どちらか 1 つだけ)。録音中は、画面の左上に「● AUDIO 0:12」が出る。

## 録画されるもの

- **映像**: ワールドと、手に持ったアイテム。**ホットバー・体力・十字線・チャット・メニューなど、画面の表示(GUI)は映らない**(GUI を描く直前の絵を取っている)。30fps。画面と同じ大きさ(幅・高さは 16 の倍数に切り下げ。たとえば 1920x1040 なら、そのまま)で、縮めない。
- **音**: ゲームの音(効果音・環境音・音楽・音符ブロックなど)。音量の設定、音の位置(左右・距離)も反映する。マイクの音は入らない。

## プレイ中は軽く、保存で時間がかかる

- **録画中**: 圧縮をしない。GPU から読み出す入れ物は、使い回す(毎回作ると重い)。動画は、いつも 30fps で作る(1/30 秒ごとの枠に、いちばん近い時刻の描画を取る)。ゲームがもともと 30fps に届かないときだけ、同じ絵が続く。画面の絵(YUV)と音(PCM)を、そのまま一時ファイルに書くだけ。ゲームのスレッドでする仕事は、GPU から読み出した絵のコピーだけで、色の変換と書き込みは、優先度の低い別のスレッドで行う。ディスクには、1 分あたり約 5GB(1920x1040、30fps の場合)の一時ファイルができる。録画の途中で、ディスクの空きが足りなくなったら、そこで止めて保存する。
- **停止したあと**: 一時ファイルから、H.264 と AAC を作って MP4 にする。録画の長さの、数分の 1〜同じくらいの時間がかかる(チャットに進み具合が出る)。ゲームの邪魔にならないよう、優先度を下げた少ないスレッドで行う。終われば、一時ファイルは消える。保存している間は、次の録画は始められない。

## ファイル形式

MP4(映像 H.264、音声 AAC-LC 44.1kHz ステレオ)。ふつうのプレーヤーや、YouTube などにそのまま使える。ffmpeg などの外部ソフトは要らない(エンコーダーは MOD の中に入っている)。

- 映像は、0.5 秒ごとのキーフレームと、その間の差分で作る(画質は、量子化 22 の高画質。色は BT.709(HD 動画の標準))。
- 保存は、停止したあとの変換で行う。録画中や変換中にゲームが強制終了すると、そのファイルは開けない(一時ファイルは残る。消してよい)。
- 一時ファイルへの書き込みが追いつかないときは、最大 30 枚(約 1 秒)まで溜めて、それでも足りなければ、フレームを飛ばして、時間は合わせる。

## 重いとき・画質や色がおかしいとき

録画を止めると、`logs/latest.log` に、次のような 1 行が出る(「録画の記録」で探す)。重さの原因を調べるのに使う。

```
録画の記録: 15.0 秒、取った絵 123 枚、描画スレッドの負荷 1 枚あたり平均 0.44 ms(全体の 0.4%)、取れなかった絵 0 枚(理想は 450 枚)
```

## 仕組み(音について)

ゲームの音は、OpenAL がスピーカーへ直接出すので、途中を横取りできない。そこで、ゲームが音の出口(`Channel`)に出す命令(音量・高さ・位置・波形のデータ)と、聞き手(`Listener`)の位置・向きを写しておいて、録画用に、同じ音を混ぜ直している。そのため、録画の音は、実際に聞こえる音に近いが、完全に同じではない(OpenAL の立体音響の計算は、簡単にしてある)。

## ビルド

`.github/workflows/build-recmod.yml`(Actions タブから実行。jar は `recmod/dist/` に保存される)。Minecraft 26.3、Fabric Loader 0.20 以降、Fabric API が必要。

H.264 のエンコードには JCodec(BSD)、AAC のハフマン表には JAAD(パブリックドメイン)の表を使っている。
