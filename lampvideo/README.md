# レッドストーンランプ動画 (Lamp Video)

動画をレッドストーンランプの点灯/消灯（白黒）で再生するデータパックを生成します。
MP3 は音声だけで映像がないので、**MP4 などの動画ファイル**を使ってください（音声があれば一緒に再生できます）。

## 速度について
コマンドは 20tick/秒なので、1tick に 1 フレームだと 30fps の動画は **2/3 倍速**になります。
既定（`--speed slow`）はこの 2/3 倍速で、全フレームを使います。音声も 2/3 に伸縮します。
`--speed normal` なら 20fps に間引いて等速で再生します。

## 使い方
```
pip install numpy pillow   # ffmpeg も必要
python3 make_lampvideo.py input.mp4 --out out --width 360 --zip
```
1. `out/lampvideo_dp_360_3tick.zip`（または `_240_3tick.zip`。どちらか1つだけ、zipのまま）を `datapacks` に、`out/lampvideo_rp_3tick` を `resourcepacks` に入れる
2. ワールドで `/reload`
3. 平らな場所で `/function lampvideo:setup`（足元が画面の左下角。南から北向きに見る）
4. `/function lampvideo:play` で再生、`/function lampvideo:stop` で停止

差分のあるランプだけ `fill` でまとめて書き換えます。360x360 は約13万個のランプで重いため、既定の出力は 240x240（約5.8万個）です。
画面全体が読み込まれる範囲（シミュレーション距離）に立ち、さらに重い場合は `--width 180` などに下げてください。
`--threshold` で白黒の閾値、`--dither` でディザを調整できます。

## 仕組みの注意
`redstone_lamp[lit=true]` を直接置くと、無電力のランプは隣のブロック更新の約4tick後に勝手に消えます。
そのためランプ自体は置きっぱなしにし、**背面のブロック**（点灯=レッドストーンブロック、消灯=黒コンクリート）を
切り替えて点灯させ、消灯のときはランプ自体も直接消灯して、4tickの遅れ（残像）が出ないようにしています。
映像の**暗い部分が点灯、明るい部分が消灯**です（線画なら線が光ります）。
また `--keyframe`（既定100フレーム）で全面を1周描き直します。1tickの負荷が跳ねないよう、画面を10本の帯に分けて少しずつ描き直し、書き込み失敗があっても自己修復します。

## 画面の高さ（重要）
画面の高さ分だけ上に伸びるため、**ワールドの高さ上限(Y=319)を超えると上の部分が描けません**。
`setup` を実行する足元の高さは、360なら **Y=-40以下**（スーパーフラットの地面 Y=-60 など）、240なら **Y=80以下** が必要です。
超えている場合は `setup` がエラー表示して止まります。通常の地形（Y=64前後）では 240 を使ってください。
画面の範囲は `setup` で常時読み込み(forceload)にします。片付けは `/function lampvideo:remove`（画面・背面・光源ブロックを消します）。
1回の `fill` は32768ブロックまでなので、大きな長方形は自動で分割しています。

## 軽量化
- `--hysteresis`（既定24）: 閾値付近のちらつきで切り替わるランプを減らす。書き換えが240で約27%、360で約16%減る
- `--hold 3`: 全フレームを3tickずつ表示（1tickあたりの負荷が約1/3）。再生速度は約0.28倍になり、音声も同じ倍率に伸びる（`*_3tick.zip`。映像・音声とも約11分30秒）
- `--width` を下げる、`--keyframe` を大きくする（全面描き直しの頻度が減る）

## 見た目の工夫
- 画面の手前に**明るさ15の光源ブロック(`light`)**を敷きます。点灯ランプの光が漏れて生じる明暗のムラ（四角い区切り）を防ぎます。
- リソースパックでランプのテクスチャを**単色**にします（消灯=暗い茶、点灯=明るい黄）。離れて見たときの格子のモアレを防ぎます。不要なら `redstone_lamp*.png` を削除してください。
- 暗い画素を点灯にしています。この動画は明るい画素が約78%なので、点灯するランプが少なく済みます。
