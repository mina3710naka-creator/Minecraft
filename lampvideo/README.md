# レッドストーンランプ動画 (Lamp Video)

動画をレッドストーンランプの点灯/消灯（白黒）で再生するデータパックと、その生成ツールです。
MP3 は音声だけで映像がないので、**MP4 などの動画ファイル**を使ってください（音声があれば一緒に再生します）。
映像の**暗い部分が点灯、明るい部分が消灯**です（線画なら線が光ります）。

## 同梱のもの（`out/240` と `out/360`。どちらか一方だけ使う）
| フォルダ | 画面 | 区間パック | 実行する高さ |
| --- | --- | --- | --- |
| `out/240` | 240×240 | 5個 | Y=80 以下 |
| `out/360` | 360×360 | 10個 | Y=-40 以下（スーパーフラットの地面など） |

各フォルダの中身: `lampvideo_base.zip`（基本）、`lampvideo_seg_01.zip` …（区間）、`lampvideo_rp`（音声とテクスチャ）。
再生は全フレームを3tickずつ表示し、約0.28倍速（約11分30秒）です。

## なぜ分かれているのか
動画全体を1つのデータパックにすると、`/reload` やワールドを開くたびに数百万個のコマンドを読み込み、
メモリが足りず「リソースを読み込み中」で止まります。そこで動画を区間パックに分け、
**再生中に1つずつ読み込んで、終わったら外す**ようにしています。
ふだん読み込まれるのは、小さな基本パックだけです。区間の切り替え時に、映像が1〜数秒止まります
（音声も区間ごとに鳴り直すので、ずれません）。

## 導入手順（最初の1回だけ手間がかかります）
区間パックは、フォルダに置いて `/reload` すると**自動で有効になります**。全部を一度に置くと、
全区間が一度に読み込まれて重くなるので、**1つずつ置いて、すぐ外します**。

1. 基本パック `lampvideo_base.zip` を `datapacks` に入れて、`/reload`。
   `[ランプ動画] 読み込み完了` と出れば成功です。
2. 区間パックごとに、次を繰り返します（`lampvideo_seg_01.zip` から順に、全部）。
   1. その zip を `datapacks` に入れる
   2. ワールドで `/reload`
   3. `/function lampvideo:release`（読み込んだ区間を外します）
3. リソースパック `lampvideo_rp` を `resourcepacks` に入れて、有効にする。
4. 平らな場所で `/function lampvideo:setup`（足元が画面の左下角。南側から北を向いて見る）。
5. `/function lampvideo:play` で再生、`/function lampvideo:stop` で停止。
   片付けは `/function lampvideo:remove`（画面・背面・光源ブロックを消します）。

> サーバーの場合は、`datapacks` は `<サーバーフォルダ>/world/datapacks/` です。
> 区間パックのファイル名（`lampvideo_seg_01.zip` など）は変えないでください。名前で切り替えています。

## 画面の高さ
画面の高さ分だけ上に伸びるため、**ワールドの高さ上限(Y=319)を超えると上の部分が描けません**。
超えている場合は `setup` がエラー表示して止まります。通常の地形（Y=64前後）では 240 を使ってください。
画面の範囲は `setup` で常時読み込み(forceload)にします。

## 見た目の工夫
- 画面の手前に**明るさ15の光源ブロック(`light`)**を敷きます。点灯ランプの光が漏れて生じる明暗のムラ（四角い区切り）を防ぎます。
- リソースパックでランプのテクスチャを**単色**にします（消灯=暗い茶、点灯=明るい黄）。離れて見たときの格子のモアレを防ぎます。不要なら `redstone_lamp*.png` を削除してください。
- `redstone_lamp[lit=true]` を直接置くと、無電力のランプは隣の更新の約4tick後に勝手に消えます。
  そのためランプは置きっぱなしにして、**背面のブロック**（点灯=レッドストーンブロック、消灯=黒コンクリート）を
  切り替えて点灯させ、消灯のときはランプ自体も直接消して、残像が出ないようにしています。
- `--keyframe`（既定100フレーム）で全面を1周描き直します。1tickの負荷が跳ねないよう、10本の帯に分けて少しずつ描き直し、
  書き込み失敗があっても自己修復します。

## 自分で作る
```
pip install numpy pillow   # ffmpeg も必要
python3 make_lampvideo.py input.mp4 --out out --width 240 --hold 3 --zip
```
- `--width`: ランプの横の数。`--hold N`: 全フレームをNtick表示（再生速度と音声もN分の1）
- `--segment-commands`: 1つの区間パックのコマンド数の目安（既定40万）。読み込みが重ければ小さくします
- `--hysteresis`（既定24）: 閾値付近のちらつきを減らす。`--threshold`: 白黒の閾値。`--dither`: ディザ
- `--speed normal`: 20fps に間引いて等速で再生（全フレームは使いません）
