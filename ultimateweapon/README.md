# 最強の武器 (Ultimate Weapons) — Minecraft データパック

「最強のクロスボウ」「最強のダイヤの剣」「雪玉（ブラックホール／凍結／巨大つらら）」の
5種類の専用武器を追加するデータパックです。すべて `minecraft:custom_data` で
専用アイテムかどうかを判定しており、**同じ種類の通常アイテムを持っていても
何も起こりません**。専用アイテムは `/function uw:give` で入手できます。

対応バージョン: Minecraft 26.2 (`pack_format` 107 / 1.21.9 以降のコンポーネント表記)

---

## 導入方法

1. `ultimateweapon` フォルダをワールドの `datapacks` フォルダにコピーします。
2. ワールドに入って `/reload` を実行します。
   `[最強の武器] 読み込み完了` と表示されれば成功です。
3. `/function uw:give` でアイテム一式を入手します（個別に配布したい場合は
   `uw:give_crossbow` / `uw:give_sword` / `uw:give_snow_blackhole` /
   `uw:give_snow_freeze` / `uw:give_snow_icicle` を使用）。
4. 操作方法は `/function uw:help` でいつでも確認できます。

### アンインストール

```
/function uw:uninstall
```
を実行してから、データパックのフォルダを削除してください。

## 最強のクロスボウ

高速装填（クイックチャージV）・無限・不可壊付き。矢を1本だけ持っていれば
（無限のため消費されません）発射できます。

- **右クリック**: 現在のモードで発射
- **Shift**（構えていない時）: モードを切り替え（1→2→3→1）

| モード | 内容 |
| --- | --- |
| 1. マシンガン | このモードでクロスボウを持っている間、手持ちのクロスボウが常に「矢が装填済み」の状態に自動で差し替えられ続ける。装填済みのクロスボウは構える動作なしで右クリック即発射なので、そのまま連射できる（矢は普通に飛んでいく本物の矢） |
| 2. 固定レーザー | 発射すると視点方向へこうもり（不可視）を瞬時に最大100ブロック飛ばして固定し、自分とそのこうもりの間に**5秒間**ビームを設置する。ビームは自分の現在地から固定された終点まで毎tick再描画されるので、動きながら振り回すこともできる（命中したMOBに約12tickごと6ダメージ）。発射した矢はその場でキルされる |
| 3. 瞬間ロックオンミサイル | 発射した**その瞬間**に、視点方向へ瞬時に最大100ブロックのレイキャストを行い、最初に見つかったMOBへ即座にロックオンして花火を一直線に発射する（照準を合わせたり長押しで選ぶ操作は無い）。MOBが見つからなければ視線方向へそのミサイルをそのまま真っ直ぐ発射する。命中地点（またはMOBに命中した地点）でエンドクリスタルが2個爆発する。発射した矢はその場でキルされる |

## 最強のダイヤの剣

不可壊付き。

- **左クリック**: 前方60ブロックへ斬撃が飛び、命中したMOBに **200ダメージ**
- **右クリック**: 自分の周囲に斬撃を2連発（それぞれ半径5ブロック、**各120ダメージ**）
- **Shift+右クリック**: 目の前4ブロック先に巨大な爆発を起こし、半径6ブロック以内のMOBに**80ダメージ**（実際に爆発を起こすのではなくダメージとエフェクトのみのため、**ブロックは一切破壊しない**）
- **Shift+左クリック**: 自分を中心に半径0→18ブロックまで0.75秒かけて広がる衝撃波を発生させ、リングが通過したMOBに**50ダメージ**

## 雪玉（3種類）

ブラックホール・凍結は、実際に飛んで**着弾した地点**で効果が発動します
（自作の弾ではなく、本物の雪玉の飛行を追跡しています）。氷結レーザーのみ、
**投げた瞬間**に即座に発動し、雪玉自体は飛ばずにその場でキルされます。

- **ブラックホール**: 着弾地点にブラックホールが発生し、半径10ブロックを5秒間吸い込む（**プレイヤー自身は吸い込まれない**）。中心（半径1ブロック）に達すると約12tickごとに押しつぶしダメージ、5秒後に崩壊して爆発ダメージ
- **凍結**: 着弾した瞬間に半径5ブロック全体へ氷のエフェクトを一度だけ広げ、範囲内のMOBを20秒間 `NoAI` 状態にして完全に行動不可にする（スロウ・採掘速度低下・弱化も付与）
- **氷結レーザー**（旧: 巨大つらら）: 投げた瞬間に雪玉自体を即座にキルし、**自分の周囲20ブロック以内の全MOBへ同時に**氷のビームを飛ばして、それぞれに**60ダメージ**を与える

## 実装メモ・既知の制約

* **レーザー・ロックオン花火が完全に機能していなかった実際の原因** —
  照準用のこうもりを `execute anchored eyes summon minecraft:bat run ...`
  という形で出していたが、`anchored eyes` は以後の `^ ^ ^` 計算の基準点を
  変えるだけで、それ単体では実行位置（position）そのものを視点まで
  移動させない。そのため、こうもりは実際にはプレイヤーの**足元付近**に
  出現しており、直後の1歩目で足元の地面に衝突してその場で止まって
  しまっていた（レイキャストがほぼ0ブロックしか伸びない）。これが
  「レーザーが何も起きない」「ミサイルが発光するだけ」の直接の原因
  だった。`positioned ^ ^ ^0` を追加し、実際に視点位置へ移動してから
  レイキャストを始めるように修正した（同じ問題が剣の前方斬撃
  `sword/slash/fire.mcfunction` にもあったため、あわせて修正済み）。
* **クロスボウのモード構成変更** — 依頼により自動追尾弾モードを廃止し、
  代わりに「マシンガンモード」を追加した。このモードでクロスボウを
  持っている間、`crossbow/machinegun/check.mcfunction` が毎tick
  「今の手持ちのクロスボウが装填済みかどうか」を確認し、装填されていなければ
  `loot_table/give/crossbow_loaded.json` 経由で装填済みのクロスボウに
  即座に差し替える。装填済みのクロスボウは構え動作が要らず右クリックで
  即発射できるバニラの仕様を利用しているため、実質的に連射になる。
  当初は `minecraft:charged_projectiles` コンポーネントの有無
  （`*[!minecraft:charged_projectiles]`）で装填状態を判定していたが、
  発射後にこのコンポーネントが「空リストとして残る」のか「完全に消える」
  のかが安定せず、うまく再判定できなかった。そのため、プレイヤー側の
  スコアボード（`uw.mgloaded` / `uw.mgloadedo`）で装填状態を自前管理する
  方式に変更した。発射を検知した瞬間（`crossbow/on_shot.mcfunction`）に
  フラグをリセットし、次のtickで `machinegun/check.mcfunction` が
  再装填する。
* **剣: 飛行モードを廃止し、Shift+右クリックに巨大爆発を割り当て** —
  依頼により飛行モード（`sword/flight/`）を削除した。当初は右クリックと
  Shift+右クリックのどちらでも周囲斬撃が発動する仕様にしていたが、
  依頼によりさらに変更し、通常の右クリックは周囲斬撃（2連発・各120
  ダメージ）のまま、Shift+右クリックには専用の「目の前に巨大な爆発を
  起こす」アビリティを新設した（`sword/dispatch_interact.mcfunction`で
  スニーク状態に応じて分岐）。実際に `/summon minecraft:tnt` や爆発
  コマンドを使うとブロックが壊れてしまうため、パーティクルと `damage`
  コマンドのみで爆発を再現しており、**地形・ブロックには一切影響しない**
  （`sword/explosion/fire.mcfunction` / `explosion/burst.mcfunction`）。
* **周囲斬撃の2発目が発動しない不具合** — バニラのMOBには被ダメージ後
  約10tick（0.5秒）の無敵時間があり、同じダメージ量をその間にもう一度
  与えても無効化される。1発目と2発目の間隔が6tickしかなかったため、
  2発目が無敵時間中に着弾し実質何も起きていなかった。間隔を無敵時間より
  長い12tickに変更した（`sword/circle/tick2.mcfunction`）。
* **レーザー・ブラックホールが毎tickダメージを与えても実質1回しか
  通っていなかった不具合** — 同じ理由（バニラの被ダメージ無敵時間）で、
  同一対象に毎tick同じダメージ量を与え続ける実装（レーザーのビーム、
  ブラックホール中心の押しつぶし）は、最初の1tickしかダメージが通らず
  実質ワンパンにしかなっていなかった。対象ごとにクールダウン用の
  スコーボード `uw.cool` を持たせ、無敵時間より長い12tick間隔でのみ
  ダメージを与えるように変更した（`crossbow/laser/damage_one.mcfunction`
  / `snow/blackhole/crush_one.mcfunction`。`uw.cool` の減衰は
  `tick.mcfunction` の後始末部分で全対象一括して行っている）。
* **衝撃波の見た目を強化** — 乱数で範囲内にばらまくだけの「雲」状の
  パーティクルでは輪として広がって見えづらかったため、45度ごと8方向
  （固定のsin/cos値を整数の現在半径に掛けて算出）にパーティクルを
  配置する方式に変更し、実際にリングが広がっていくように見えるようにした
  （`sword/shockwave/tick.mcfunction` / `shockwave/expand.mcfunction`）。
* **雪玉: 本物の雪玉を追跡する方式に全面刷新** — 自作の弾を飛ばす方式を
  2回試したがいずれも実機で機能しなかったため、方針を変更し、**本物の
  雪玉をそのまま飛ばして**（バニラの物理演算に任せて）、統計
  `minecraft.used:minecraft.snowball` で投げた瞬間を検知した直後に
  近くの雪玉本体へタグを付け、透明な追跡用マーカーをその位置に生成して
  毎tick追従させる。雪玉が着弾して消滅した瞬間（＝マーカーが最後に
  同期した位置）を着弾地点として効果を発動する
  （`snow/*/mark_thrown.mcfunction` 〜 `tracker_land.mcfunction`）。
  これにより「着弾地点で発動」を文字通り実現しており、雪玉本来の
  放物線の軌道もそのまま活きる。
* **つらら→巨大な氷塊→氷結レーザーへと変遷** — 当初は5秒間つらら（鍾乳石）
  を降らせる範囲攻撃、次に着弾地点の真上から巨大な氷塊が1体落ちてくる
  方式（見た目の巨大化に `minecraft:block_display` + `transformation`
  を使ったが、これは純粋な見た目上の表示エンティティで当たり判定・落下
  ともに実体を伴わず、着弾判定が一切機能しなかった。`minecraft:falling_block`
  + `NoGravity:1b` + 自前 `tp` 降下方式に直した）と2回作り直したが、
  依頼によりさらに方式を変更し、**着弾を待つこと自体をやめた**。今は
  投げた瞬間（雪玉を投げたことを検知した瞬間）に本物の雪玉を即座に
  キルし、自分の周囲20ブロック以内の全MOBへ同時にダメージと
  ビーム状のパーティクルを飛ばす、瞬間発動のAoE攻撃になっている
  （`snow/icicle/mark_thrown.mcfunction` 〜 `laser_beam_*.mcfunction`）。
  ビームの描画は、対象を1体ずつ `uw.icetgt` タグで管理し、視点をその
  対象へ向けてレーザーと同じ手法で1ブロックずつ描画しては次の対象へ
  進む、という単純な逐次処理で実現している。
* **専用アイテムの判定** — すべて `minecraft:custom_data` に固有のフラグ
  （`uw_crossbow` / `uw_sword` / `uw_snow_blackhole` 等）を付けて判定している。
  同じ見た目のアイテムでも、このフラグが無ければ一切反応しない。
* **クロスボウのエンチャント・装填状態** — `give` コマンドの
  `minecraft:enchantments={levels:{...}}` という書き方は、このリポジトリの
  過去の検証（spiderweb パック開発時）で実際にゲームから拒否されることが
  確認されている。そのため本パックでは `loot_table` の
  `minecraft:set_enchantments` / `minecraft:set_components` 関数を使い、
  `/loot give` や `/loot replace` 経由でクイックチャージV・無限・
  （マシンガンモードでは）装填状態を安定して付与している。
* **クロスボウの発射検知** — 当初は `execute on owner` で「矢の持ち主が
  専用アイテムを構えていたか」を判定していたが、実機で反応しない不具合が
  確認されたため、モード切替と同じ「専用アイテムを持っているプレイヤー
  自身を毎tick直接確認し、自分の近く（4ブロック以内）に未処理の矢が
  出現していないか調べる」方式に変更した（`crossbow/check_fire.mcfunction`）。
  この方式の副作用として、専用アイテムを持ったまま「他人が撃った矢」や
  「地面に落ちている未処理の矢」に4ブロック以内まで近づくと、誤って
  自分が発射したものとして扱われることがごく稀にある。
* **剣のクリック検知** — 通常の左クリック（振り攻撃）は、何かに命中しない限り
  サーバー側でほぼ検知できないため、`minecraft:interaction` エンティティを
  プレイヤーの視点位置に常駐させ、その `attack` / `interaction` タグの
  有無（見つけたら即削除して消費）で左右クリックを検知している
  （`sword/interact/`）。この方式はクロスボウの発射（構える動作）と
  衝突することがこのリポジトリの過去の検証で確認されているため、
  **最強のダイヤの剣を持っている間だけ**インタラクションエンティティを
  配置し、持ち替えたら即座に片付けるようにしている。なお、この仕組みの
  都合上、剣を持っている間は他のMOB・ブロックへの通常の右クリック操作
  （チェストを開く等）が行えなくなる。右クリックが反応しない不具合の
  対策として、未検証だった `response:1b` NBTフィールドを外し、
  ヒットボックスを `1.2` → `1.8` に拡大したほか、`uw.has_interact`
  タグはあるのにインタラクション実体そのものが消えている場合（何らかの
  理由で `kill` された等）にタグを外して自動再生成する保険を
  `sword/interact/ensure.mcfunction` に追加した。
* **ミサイルモードの選択ステップを廃止し、発射した瞬間に飛ばす方式へ変更** —
  以前はクロスボウを一時的に本物のスパイグラスへ入れ替えて右クリック
  長押しでズーム→毎tick再ロックオン→離した瞬間に発射、という多段階の
  操作だったが、この「離した瞬間」の判定がズーム開始直後の数tickで
  誤作動しやすく、また「発射の文字は出るのにミサイルが飛ばない」
  （`facing entity @e[tag=uw.locktgt]` がロックオン対象皆無の場合に
  コマンドチェーン全体を静かに失敗させていたことが原因）といった不具合が
  解消しきらなかった。依頼により、そもそも選択ステップ自体を廃止し、
  **矢を発射した瞬間に視点方向へその場でレイキャストしてロックオンし、
  即座にミサイルを発射する**方式（`crossbow/zoom/instant_*.mcfunction`）に
  作り直した。ロックオン対象はタグ（`uw.locktgt`）で管理しているため、
  複数のプレイヤーが同時にこのモードを使うと稀に混線する場合がある
  （単独プレイ・少人数協力プレイを想定）。
* **ミサイルのレイキャストが視線と無関係な方向へ飛んでいた不具合** —
  「発射した瞬間にレイキャスト」方式に作り直した際、レイキャスト用の
  こうもりを `summon` した直後に `tp @s ~ ~ ~ ~ ~`（summon 時の実行
  コンテキスト＝プレイヤーの視点の回転を明示的に引き継がせるための
  定型句。レーザーの照準用こうもりでは元から使われていた）を入れ忘れて
  いた。これが無いとこうもりはバニラのデフォルト回転のまま出現し、
  以後の `^ ^ ^1` 前進が視線と無関係な方向に飛んでいってしまい、
  ロックオンも直進発射もまともに機能していなかった。`instant_probe_init.mcfunction`
  に追加して修正した。
* **氷結エフェクトのパーティクルIDタイプミス** — 凍結の着弾エフェクトに
  追加した `minecraft:item_snowball` という粒子は存在しないIDで
  （アイテムを表示する粒子は `minecraft:item <アイテムID>` という形式が
  正しい）、このコマンドだけがエラーで失敗していた。`minecraft:item
  minecraft:snowball` に修正した。
* **被ダメージ無敵時間クールダウンの判定をより堅牢な書き方に変更** —
  レーザー・ブラックホールのダメージクールダウン判定を、存在しない
  スコアに対する `unless score ... matches 1..` という否定形の判定から、
  `scoreboard players add @s uw.cool 0` で明示的にスコアを初期化してから
  `if score ... matches ..0` で判定する形に変更し、スコア未設定時の
  挙動に依存しない書き方にした。
* **ブラックホールのエフェクトが持続中ずっと再生されるよう強化** —
  エフェクト自体は元から毎tick再生されていたが、視覚的に「常に活動して
  いる」と分かりやすいよう、パーティクルの種類・密度を増やし
  （`minecraft:soul_fire_flame` や紫の `minecraft:dust` を追加）、
  環境音の音量も上げた（`snow/blackhole/tick.mcfunction`）。
* **ダメージ量** — 依頼文に数値の指定が無かったアビリティ（レーザー・
  周囲斬撃の半径・衝撃波・ブラックホール・巨大つらら等の一部）は、
  「最強の武器」というコンセプトに沿ってこちらで妥当な値を設定した。
  上の「調整できる数値」の該当ファイルを書き換えれば自由に変更できる。
