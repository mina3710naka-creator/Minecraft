# 最強の武器 (Ultimate Weapons) — Minecraft データパック

「最強のクロスボウ」「最強のダイヤの剣」「雪玉（ブラックホール／凍結／つらら）」の
5種類の専用武器を追加するデータパックです。すべて `minecraft:custom_data` で
専用アイテムかどうかを判定しており、**同じ種類の通常アイテムを持っていても
何も起こりません**。専用アイテムは `/function uw:give` で入手できます。

対応バージョン: Minecraft 26.2 (`pack_format` 107 / 1.21.9 以降のコンポーネント表記)

---

## 導入方法

1. `ultimateweapon` フォルダをワールドの `datapacks` フォルダにコピーします。
2. ワールドに入って `/reload` を実行します。
   `[最強の武器] 読み込み完了` と表示されれば成功です。
3. `/function uw:give` でアイテム一式を入手します（個別に配布したい場合は
   `uw:give_crossbow` / `uw:give_sword` / `uw:give_snow_blackhole` /
   `uw:give_snow_freeze` / `uw:give_snow_icicle` を使用）。
4. 操作方法は `/function uw:help` でいつでも確認できます。

### アンインストール

```
/function uw:uninstall
```
を実行してから、データパックのフォルダを削除してください。

## 最強のクロスボウ

高速装填（クイックチャージV）・無限・不可壊付き。矢を1本だけ持っていれば
（無限のため消費されません）発射できます。

- **右クリック**: 現在のモードで発射
- **Shift**（構えていない時）: モードを切り替え（1→2→3→1）

| モード | 内容 |
| --- | --- |
| 1. 自動追尾弾 | 発射すると一番近いMOBへ向きを変えながら飛び、命中で **20ダメージ** |
| 2. 持続レーザー | 0.75秒間、視線方向に高速のビームを撃ち続ける（命中したMOBに毎tick 6ダメージ） |
| 3. ロックオン花火 | 右クリックで本物の望遠鏡（スパイグラス）に変身しズーム。MOBに照準を合わせて右クリックを離すと花火が発射され、命中地点でエンドクリスタルが2個爆発する。Shiftを押しながら離すとキャンセル |

## 最強のダイヤの剣

不可壊付き。

- **左クリック**: 前方60ブロックへ斬撃が飛び、命中したMOBに **200ダメージ**
- **右クリック**: 自分の周囲に斬撃を2連発（それぞれ半径5ブロック、**各120ダメージ**）
- **Shift+右クリック**: 飛行モードの切替（上を見ながら移動すると上昇、常時スローフォールで落下ダメージ無効）
- **Shift+左クリック**: 周囲20ブロックのランダムな位置に「剣の雨」（トライデント12本）を降らせ、着弾地点に範囲ダメージ

---

## 雪玉（3種類）

投げるだけで発動します。

- **ブラックホール**: 着弾地点にブラックホールが発生し、半径10ブロックを5秒間吸い込む。中心（半径1ブロック）に達すると毎tick押しつぶしダメージ、5秒後に崩壊して爆発ダメージ
- **凍結**: 着弾地点から半径5ブロック以内のMOBを20秒間 `NoAI` 状態にして完全に行動不可にする（スロウ・採掘速度低下・弱化も付与）
- **つらら**: 着弾地点の周囲10ブロックに5秒間、本物の鍾乳石（つらら）を降らせる。バニラの落下鍾乳石の仕様で着地時にダメージが入る（着地後はブロックとしてその場に残ります）

## 調整できる数値

| 内容 | ファイル |
| --- | --- |
| 自動追尾弾の速度・射程・ダメージ | `crossbow/homing/tick.mcfunction` / `homing/hit.mcfunction` |
| レーザーの持続時間・射程・ダメージ | `crossbow/laser/fire.mcfunction`（`uw.t 15`）/ `laser/step.mcfunction` |
| ロックオン範囲・花火の速度 | `crossbow/zoom/aim_scan.mcfunction` / `zoom/firework_step.mcfunction` |
| 斬撃の射程・ダメージ | `sword/slash/fire.mcfunction` / `slash/hit_one.mcfunction` |
| 周囲斬撃の半径・ダメージ・間隔 | `sword/circle/burst.mcfunction` / `circle/tick2.mcfunction` |
| 飛行の上昇量 | `sword/flight/tick.mcfunction`（レビテーションの強さ・pitch閾値） |
| 剣の雨の本数・範囲・ダメージ | `sword/rain/fire.mcfunction`（呼び出し回数）/ `rain/spawn_one.mcfunction`（`-14..14`）/ `rain/impact.mcfunction` |
| ブラックホールの半径・持続・ダメージ | `snow/blackhole/tick.mcfunction` / `pull_one.mcfunction` / `collapse.mcfunction` |
| 凍結時間・範囲 | `snow/freeze/hit.mcfunction`（`distance=..5`）/ `apply_one.mcfunction`（`uw.t 400`＝20秒） |
| つららの範囲・頻度・持続 | `snow/icicle/tick.mcfunction`（`uw.t 100`＝5秒、`random value 1..3`）/ `spawn_drip.mcfunction`（`-10..10`） |

## 実装メモ・既知の制約

* **専用アイテムの判定** — すべて `minecraft:custom_data` に固有のフラグ
  （`uw_crossbow` / `uw_sword` / `uw_snow_blackhole` 等）を付けて判定している。
  同じ見た目のアイテムでも、このフラグが無ければ一切反応しない。
* **クロスボウのエンチャント** — `give` コマンドの `minecraft:enchantments={levels:{...}}`
  という書き方は、このリポジトリの過去の検証（spiderweb パック開発時）で
  実際にゲームから拒否されることが確認されている。そのため本パックでは
  `loot_table` の `minecraft:set_enchantments` 関数を使い、`/loot give` 経由で
  クイックチャージV・無限を安定して付与している（`give_crossbow.mcfunction`）。
* **クロスボウの発射検知** — クロスボウの「構える→離す」を統計だけで判定するのは
  不安定なため（同じくこのリポジトリで過去に確認済み）、実際に矢が出現した
  瞬間を発射の合図として使う（`crossbow/detect_shot.mcfunction`）。見た目用の
  矢は即座にキルし、代わりに自作の弾（自動追尾弾・レーザー・花火）を飛ばす。
* **ロックオン花火のズーム演出** — バニラのズーム（視野角の拡大）はスパイグラス
  という特定のアイテムにのみ働くクライアント側の演出のため、クロスボウを
  一時的に本物のスパイグラス（`loot_table/give/aim_spyglass.json`）に入れ替える
  ことで実現している。離す（`minecraft:using_item` アドバンスメントの発火が
  途切れる）と自動的に本物のクロスボウへ戻る。ロックオン対象は
  タグ（`uw.locktgt`）で管理しているため、**複数のプレイヤーが同時にこの
  モードを使うと、ロックオン対象が混線する場合がある**（単独プレイ・少人数
  協力プレイを想定）。
* **剣のクリック検知** — 通常の左クリック（振り攻撃）は、何かに命中しない限り
  サーバー側でほぼ検知できないため、`minecraft:interaction` エンティティを
  プレイヤーの視点位置に常駐させ、その `attack` / `interaction` フィールドの
  変化で左右クリックを検知している（`sword/interact/`）。この方式は
  クロスボウの発射（構える動作）と衝突することがこのリポジトリの過去の
  検証で確認されているため、**最強のダイヤの剣を持っている間だけ**インタラクション
  エンティティを配置し、持ち替えたら即座に片付けるようにしている。
  なお、この仕組みの都合上、剣を持っている間は他のMOB・ブロックへの通常の
  右クリック操作（チェストを開く等）が行えなくなる。
* **飛行モード** — バニラのコマンドには「クリエイティブ飛行を許可する」機能が
  無いため（`/data modify entity` はプレイヤーへの適用が禁止されている）、
  スローフォール（常時）とレビテーション（上を見た時だけ微量に付与）を
  組み合わせた擬似的な飛行で再現している。本物の飛行ほど自由な操作感には
  ならない点に注意。
* **雪玉の判定** — 投げた瞬間に出現する矢と同様、`on owner` で投げた本人の
  手持ちアイテムを確認している。スタックの最後の1個を投げた場合、投げた
  瞬間には手が空になっているため、ごく稀に反応しないことがある
  （気になる場合はスタックを分けて持つか、`give_snow_*` で数を増やして
  補充してください）。
* **ダメージ量** — 依頼文に数値の指定が無かったアビリティ（レーザー・
  周囲斬撃の半径・剣の雨・ブラックホール・つらら等の一部）は、「最強の武器」
  というコンセプトに沿ってこちらで妥当な値を設定した。上の「調整できる数値」
  の該当ファイルを書き換えれば自由に変更できる。

## ファイル構成

```
ultimateweapon/
├── pack.mcmeta
└── data/
    ├── minecraft/tags/function/   … tick / load への登録
    └── uw/
        ├── predicate/sneaking.json
        ├── advancement/using_item.json   … ズーム中の判定に使用
        ├── loot_table/give/              … クロスボウ・ズーム用スパイグラスの配布
        └── function/
            ├── load / tick / give* / uninstall / help
            ├── crossbow/  … 発射検知・3モード（追尾弾・レーザー・ロックオン花火）
            ├── sword/     … クリック検知・斬撃・周囲斬撃・飛行・剣の雨
            ├── snow/      … 3種類の雪玉（ブラックホール・凍結・つらら）
            └── util/      … 後始末・安全装置
```
