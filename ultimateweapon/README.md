# 最強の武器 (Ultimate Weapons) — Minecraft データパック

「最強のクロスボウ」「最強のダイヤの剣」「雪玉（ブラックホール／凍結／巨大つらら）」の
5種類の専用武器を追加するデータパックです。すべて `minecraft:custom_data` で
専用アイテムかどうかを判定しており、**同じ種類の通常アイテムを持っていても
何も起こりません**。専用アイテムは `/function uw:give` で入手できます。

対応バージョン: Minecraft 26.2 (`pack_format` 107 / 1.21.9 以降のコンポーネント表記)

---

## 導入方法

1. `ultimateweapon` フォルダをワールドの `datapacks` フォルダにコピーします。
2. ワールドに入って `/reload` を実行します。
   `[最強の武器] 読み込み完了` と表示されれば成功です。
3. `/function uw:give` でアイテム一式を入手します（個別に配布したい場合は
   `uw:give_crossbow` / `uw:give_sword` / `uw:give_snow_blackhole` /
   `uw:give_snow_freeze` / `uw:give_snow_icicle` を使用）。
4. 操作方法は `/function uw:help` でいつでも確認できます。

### アンインストール

```
/function uw:uninstall
```
を実行してから、データパックのフォルダを削除してください。

## 最強のクロスボウ

高速装填（クイックチャージV）・無限・不可壊付き。矢を1本だけ持っていれば
（無限のため消費されません）発射できます。

- **右クリック**: 現在のモードで発射
- **Shift**（構えていない時）: モードを切り替え（1→2→3→1）

| モード | 内容 |
| --- | --- |
| 1. マシンガン | このモードでクロスボウを持っている間、手持ちのクロスボウが常に「矢が装填済み」の状態に自動で差し替えられ続ける。装填済みのクロスボウは構える動作なしで右クリック即発射なので、そのまま連射できる（矢は普通に飛んでいく本物の矢） |
| 2. 固定レーザー | 発射すると視点方向へこうもり（不可視）を瞬時に最大100ブロック飛ばして固定し、自分とそのこうもりの間に**5秒間**ビームを設置する。ビームは自分の現在地から固定された終点まで毎tick再描画されるので、動きながら振り回すこともできる（命中したMOBに10tickごと15ダメージ）。発射した矢はその場でキルされる |
| 3. ロックオン花火 | 右クリックで本物の望遠鏡（スパイグラス）に変身しズーム。ズーム中は視点方向へこうもりを毎tick瞬時に最大100ブロック飛ばし、その道中に最も近いMOBがいれば発光させる。右クリックを離した瞬間、こうもりを消して発光中のMOBにロックオンタグを付け、そのMOBへ向けて花火を一直線に発射。命中地点でエンドクリスタルが2個爆発する。Shiftを押しながら離すとキャンセル。発射した矢はその場でキルされる |

## 最強のダイヤの剣

不可壊付き。

- **左クリック**: 前方60ブロックへ斬撃が飛び、命中したMOBに **200ダメージ**
- **右クリック / Shift+右クリック**: 自分の周囲に斬撃を2連発（それぞれ半径5ブロック、**各120ダメージ**）
- **Shift+左クリック**: 自分を中心に半径0→18ブロックまで0.75秒かけて広がる衝撃波を発生させ、リングが通過したMOBに**50ダメージ**

## 雪玉（3種類）

投げると、実際に飛んで**着弾した地点**で効果が発動します（自作の弾ではなく、
本物の雪玉の飛行を追跡しています）。

- **ブラックホール**: 着弾地点にブラックホールが発生し、半径10ブロックを5秒間吸い込む（プレイヤーは吸い込まれません）。中心（半径1ブロック）に達すると10tickごとに8ダメージ、5秒後に崩壊して爆発ダメージ
- **凍結**: 着弾地点から半径5ブロック以内のMOBを20秒間 `NoAI` 状態にして完全に行動不可にする（スロウ・採掘速度低下・弱化も付与）
- **巨大つらら**: 着弾地点の真上、20ブロック上空に氷塊が出現し、落下してくる。MOBに当たるか地面に着くと**100ダメージ**を与えて消える

## 実装メモ・既知の制約

* **バニラの被ダメージ無敵時間による「ダメージが通らない」不具合（複数箇所）** —
  MOBは1度ダメージを受けると約10tick（0.5秒）の間、**同じか
  それ以下のダメージ量**を無効化する無敵時間に入る。レーザー
  （毎tick同じ6ダメージ）とブラックホールの押しつぶし（毎tick同じ
  4ダメージ）は、この仕様のせいで実質「最初の1tickしかダメージが
  通らない」状態になっていた（周囲斬撃の2発目が無効化されていたのと
  全く同じ原因）。対象ごとにクールダウン（`uw.cool`）を持たせ、
  無敵時間より長い10tick間隔でのみ再ヒットするように修正し、1回
  あたりのダメージ量も見直した（レーザー: 6→15/10tick、
  ブラックホール中心: 4→8/10tick）。
* **こうもりが見えてしまう不具合** — `Invisible:1b` だけに頼っていたが
  念のため無限時間の透明化エフェクト（`minecraft:invisibility`）も
  重ねて付与するようにした（レーザー・ロックオン花火どちらのこうもりも）。
* **マシンガンモードが機能しない不具合** — アイテムの
  `charged_projectiles` コンポーネントの有無を `*[!minecraft:...]`
  という否定記法で直接調べていたが、この書き方自体が版によって
  正しく機能しない可能性があったため使用をやめ、代わりに自前のスコア
  （`uw.mgloaded`）で「今装填済みを渡したかどうか」を管理する方式に
  変更した。発射を検知した瞬間にフラグを下ろし、次のtickで
  `crossbow/machinegun/check.mcfunction` が確認して再装填する。
* **ロックオン花火が発射されない不具合（「発射！」の表示だけ出る）** —
  2つの原因が重なっていた。①`using_item` の猶予判定が0/1の一発勝負
  だったため、`minecraft:using_item` がたまたま毎tick発火しなかった
  瞬間があると「離した」と誤判定し、ロックオンが完了する前に
  発射／キャンセルされていた（→6tick分の猶予バッファ方式に変更）。
  ②ロックオン対象が居ない状態で `facing entity @e[tag=uw.locktgt]`
  を実行すると対象セレクターが誰にもマッチせず**コマンド全体が失敗**
  し、それより後ろに書いていた発射処理（summon以降）が丸ごと
  実行されなかった（先に書いていた `title` の「発射！」表示だけは
  通っていたため、表示は出るのに何も飛ばないという症状になっていた）。
  ロックオンの有無で分岐し、対象が無ければ現在の視線方向へ直進する
  ように修正した（`zoom/fire.mcfunction` / `fire_at_target.mcfunction` /
  `fire_straight.mcfunction`）。
* **つらら（巨大な氷塊）が全く着弾しない不具合** — `minecraft:block_display`
  の拡大縮小表示（`transformation`）で「見た目3倍の氷塊」を試みたが
  実機で全く機能しなかった。このパック内で既に実績のある
  `minecraft:falling_block`（`BlockState` 指定）＋ `NoGravity` 手動制御
  という、つらら雨の時代から使っていた技術に戻した。見た目の巨大化は
  諦め、代わりにパーティクルを強化して「大きな塊が落ちてくる」印象を
  出している（`snow/icicle/giant_*`）。
* **ブラックホールにプレイヤーが吸い込まれる不具合** — 吸い込み対象の
  選択条件に `type=!minecraft:player` を追加し、MOB・アイテム等のみ
  引き寄せるようにした。あわせて発生時・持続中のパーティクルと
  効果音を大幅に強化した（`snow/blackhole/tick.mcfunction` /
  `tracker_land.mcfunction`）。
* **凍結エフェクトを着弾範囲全体に一度だけ** — 着弾点だけに集中していた
  パーティクルを、半径5ブロック全体に広がるよう spread パラメータを
  拡大し、雪・氷ブロック・氷片など複数種類のパーティクルを組み合わせて
  「範囲全体が一瞬で凍りつく」演出にした（`snow/freeze/hit.mcfunction`）。
* **剣の右クリックが安定しない件** — インタラクションエンティティに
  設定していた `response:1b` は正しいフィールド名か確証が持てなかった
  ため削除し、判定用の当たり判定を少し大きく（1.2→1.6）して取りこぼしを
  減らした。左クリック（攻撃）と全く同じ仕組みで右クリックも検知して
  いるため、構造上の左右差は無いはずだが、原因を完全には特定できて
  いない。まだ改善しない場合は教えてほしい。
* **衝撃波は廃止した剣の雨の後継技** — Shift+左クリック用の技として、
  上空からトライデントを降らせる「剣の雨」を、自分を中心に広がる
  リング状の「衝撃波」に置き換えている。
* **レーザー・ロックオン花火が完全に機能していなかった実際の原因** —
  照準用のこうもりを `execute anchored eyes summon minecraft:bat run ...`
  という形で出していたが、`anchored eyes` は以後の `^ ^ ^` 計算の基準点を
  変えるだけで、それ単体では実行位置（position）そのものを視点まで
  移動させない。そのため、こうもりは実際にはプレイヤーの**足元付近**に
  出現しており、直後の1歩目で足元の地面に衝突してその場で止まって
  しまっていた（レイキャストがほぼ0ブロックしか伸びない）。これが
  「レーザーが何も起きない」「ミサイルが発光するだけ」の直接の原因
  だった。`positioned ^ ^ ^0` を追加し、実際に視点位置へ移動してから
  レイキャストを始めるように修正した（同じ問題が剣の前方斬撃
  `sword/slash/fire.mcfunction` にもあったため、あわせて修正済み）。
* **剣: 飛行モードを廃止し、周囲斬撃をShift+右クリックにも割り当て** —
  依頼により飛行モード（`sword/flight/`）を削除し、右クリックと
  Shift+右クリックのどちらでも周囲斬撃（2連発・各120ダメージ）が
  発動するようにした（`sword/dispatch_interact.mcfunction`）。
* **周囲斬撃の2発目が発動しない不具合** — バニラのMOBには被ダメージ後
  約10tick（0.5秒）の無敵時間があり、同じダメージ量をその間にもう一度
  与えても無効化される。1発目と2発目の間隔が6tickしかなかったため、
  2発目が無敵時間中に着弾し実質何も起きていなかった。間隔を無敵時間より
  長い12tickに変更した（`sword/circle/tick2.mcfunction`）。
* **衝撃波の見た目を強化** — 乱数で範囲内にばらまくだけの「雲」状の
  パーティクルでは輪として広がって見えづらかったため、45度ごと8方向
  （固定のsin/cos値を整数の現在半径に掛けて算出）にパーティクルを
  配置する方式に変更し、実際にリングが広がっていくように見えるようにした
  （`sword/shockwave/tick.mcfunction` / `shockwave/expand.mcfunction`）。
* **雪玉: 本物の雪玉を追跡する方式に全面刷新** — 自作の弾を飛ばす方式を
  2回試したがいずれも実機で機能しなかったため、方針を変更し、**本物の
  雪玉をそのまま飛ばして**（バニラの物理演算に任せて）、統計
  `minecraft.used:minecraft.snowball` で投げた瞬間を検知した直後に
  近くの雪玉本体へタグを付け、透明な追跡用マーカーをその位置に生成して
  毎tick追従させる。雪玉が着弾して消滅した瞬間（＝マーカーが最後に
  同期した位置）を着弾地点として効果を発動する
  （`snow/*/mark_thrown.mcfunction` 〜 `tracker_land.mcfunction`）。
  これにより「着弾地点で発動」を文字通り実現しており、雪玉本来の
  放物線の軌道もそのまま活きる。
* **専用アイテムの判定** — すべて `minecraft:custom_data` に固有のフラグ
  （`uw_crossbow` / `uw_sword` / `uw_snow_blackhole` 等）を付けて判定している。
  同じ見た目のアイテムでも、このフラグが無ければ一切反応しない。
* **クロスボウのエンチャント・装填状態** — `give` コマンドの
  `minecraft:enchantments={levels:{...}}` という書き方は、このリポジトリの
  過去の検証（spiderweb パック開発時）で実際にゲームから拒否されることが
  確認されている。そのため本パックでは `loot_table` の
  `minecraft:set_enchantments` / `minecraft:set_components` 関数を使い、
  `/loot give` や `/loot replace` 経由でクイックチャージV・無限・
  （マシンガンモードでは）装填状態を安定して付与している。
* **クロスボウの発射検知** — 当初は `execute on owner` で「矢の持ち主が
  専用アイテムを構えていたか」を判定していたが、実機で反応しない不具合が
  確認されたため、モード切替と同じ「専用アイテムを持っているプレイヤー
  自身を毎tick直接確認し、自分の近く（4ブロック以内）に未処理の矢が
  出現していないか調べる」方式に変更した（`crossbow/check_fire.mcfunction`）。
  この方式の副作用として、専用アイテムを持ったまま「他人が撃った矢」や
  「地面に落ちている未処理の矢」に4ブロック以内まで近づくと、誤って
  自分が発射したものとして扱われることがごく稀にある。
* **剣のクリック検知** — 通常の左クリック（振り攻撃）は、何かに命中しない限り
  サーバー側でほぼ検知できないため、`minecraft:interaction` エンティティを
  プレイヤーの視点位置に常駐させ、その `attack` / `interaction` タグの
  有無（見つけたら即削除して消費）で左右クリックを検知している
  （`sword/interact/`）。この方式はクロスボウの発射（構える動作）と
  衝突することがこのリポジトリの過去の検証で確認されているため、
  **最強のダイヤの剣を持っている間だけ**インタラクションエンティティを
  配置し、持ち替えたら即座に片付けるようにしている。なお、この仕組みの
  都合上、剣を持っている間は他のMOB・ブロックへの通常の右クリック操作
  （チェストを開く等）が行えなくなる。
* **ロックオン花火のズーム演出** — バニラのズーム（視野角の拡大）はスパイグラス
  という特定のアイテムにのみ働くクライアント側の演出のため、クロスボウを
  一時的に本物のスパイグラス（`loot_table/give/aim_spyglass.json`）に入れ替える
  ことで実現している。離す（`minecraft:using_item` アドバンスメントの発火が
  途切れる）と自動的に本物のクロスボウへ戻る。ロックオン対象は
  タグ（`uw.locktgt`）で管理しているため、**複数のプレイヤーが同時にこの
  モードを使うと、ロックオン対象が混線する場合がある**（単独プレイ・少人数
  協力プレイを想定）。
* **ダメージ量** — 依頼文に数値の指定が無かったアビリティ（レーザー・
  周囲斬撃の半径・衝撃波・ブラックホール・巨大つらら等の一部）は、
  「最強の武器」というコンセプトに沿ってこちらで妥当な値を設定した。
  上の「調整できる数値」の該当ファイルを書き換えれば自由に変更できる。

## ファイル構成

```
ultimateweapon/
├── pack.mcmeta
└── data/
    ├── minecraft/tags/function/   … tick / load への登録
    └── uw/
        ├── predicate/sneaking.json
        ├── advancement/using_item.json   … ズーム中の判定に使用
        ├── loot_table/give/              … クロスボウ・装填済みクロスボウ・ズーム用スパイグラスの配布
        └── function/
            ├── load / tick / give* / uninstall / help
            ├── crossbow/  … 発射検知・3モード（マシンガン・固定レーザー・ロックオン花火）
            ├── sword/     … クリック検知・斬撃・周囲斬撃・衝撃波
            ├── snow/      … 3種類の雪玉（ブラックホール・凍結・巨大つらら）
            └── util/      … 後始末・安全装置
```
