# 最強の武器 (Ultimate Weapons) — Minecraft データパック

「最強のクロスボウ」「最強のダイヤの剣」「雪玉（ブラックホール／凍結／つらら）」の
5種類の専用武器を追加するデータパックです。すべて `minecraft:custom_data` で
専用アイテムかどうかを判定しており、**同じ種類の通常アイテムを持っていても
何も起こりません**。専用アイテムは `/function uw:give` で入手できます。

対応バージョン: Minecraft 26.2 (`pack_format` 107 / 1.21.9 以降のコンポーネント表記)

---

## 導入方法

1. `ultimateweapon` フォルダをワールドの `datapacks` フォルダにコピーします。
2. ワールドに入って `/reload` を実行します。
   `[最強の武器] 読み込み完了` と表示されれば成功です。
3. `/function uw:give` でアイテム一式を入手します（個別に配布したい場合は
   `uw:give_crossbow` / `uw:give_sword` / `uw:give_snow_blackhole` /
   `uw:give_snow_freeze` / `uw:give_snow_icicle` を使用）。
4. 操作方法は `/function uw:help` でいつでも確認できます。

### アンインストール

```
/function uw:uninstall
```
を実行してから、データパックのフォルダを削除してください。

## 最強のクロスボウ

高速装填（クイックチャージV）・無限・不可壊付き。矢を1本だけ持っていれば
（無限のため消費されません）発射できます。

- **右クリック**: 現在のモードで発射
- **Shift**（構えていない時）: モードを切り替え（1→2→3→1）

| モード | 内容 |
| --- | --- |
| 1. 自動追尾弾 | 発射した瞬間、視点方向に一番近いMOBをロックオン。矢はそのMOBへ向きを変えながら飛び続け、命中で **80ダメージ** |
| 2. 固定レーザー | 発射すると視点方向へこうもり（不可視）を瞬時に最大100ブロック飛ばして固定し、自分とそのこうもりの間に**5秒間**ビームを設置する。ビームは自分の現在地から固定された終点まで毎tick再描画されるので、動きながら振り回すこともできる（命中したMOBに毎tick 6ダメージ） |
| 3. ロックオン花火 | 右クリックで本物の望遠鏡（スパイグラス）に変身しズーム。ズーム中は視点方向へこうもりを毎tick瞬時に最大100ブロック飛ばし、その道中に最も近いMOBがいれば発光させる。右クリックを離した瞬間、こうもりを消して発光中のMOBにロックオンタグを付け、そのMOBへ向けて花火を一直線に発射。命中地点でエンドクリスタルが2個爆発する。Shiftを押しながら離すとキャンセル |

## 最強のダイヤの剣

不可壊付き。

- **左クリック**: 前方60ブロックへ斬撃が飛び、命中したMOBに **200ダメージ**
- **右クリック**: 自分の周囲に斬撃を2連発（それぞれ半径5ブロック、**各120ダメージ**）
- **Shift+右クリック**: 飛行モードの切替（上を見ながら移動すると上昇、常時スローフォールで落下ダメージ無効）
- **Shift+左クリック**: 自分を中心に半径0→18ブロックまで0.75秒かけて広がる衝撃波を発生させ、リングが通過したMOBに**50ダメージ**

## 雪玉（3種類）

投げるだけで発動します。

- **ブラックホール**: 着弾地点にブラックホールが発生し、半径10ブロックを5秒間吸い込む。中心（半径1ブロック）に達すると毎tick押しつぶしダメージ、5秒後に崩壊して爆発ダメージ
- **凍結**: 着弾地点から半径5ブロック以内のMOBを20秒間 `NoAI` 状態にして完全に行動不可にする（スロウ・採掘速度低下・弱化も付与）
- **つらら**: 着弾地点の周囲10ブロックに5秒間、本物の鍾乳石（つらら）を降らせる。バニラの落下鍾乳石の仕様で着地時にダメージが入る（着地後はブロックとしてその場に残ります）

## 実装メモ・既知の制約

* **雪玉の投擲検知（3度目の修正）** — 「近くの未処理の雪玉を探す」方式を
  2回試したが実機で機能しなかったため、hookshotの釣り竿と全く同じ、
  実績のある統計 `minecraft.used:minecraft.snowball` ベースの検知に
  差し替えた（`load.mcfunction` の `uw.snowuse` / `snow/detect_throw.mcfunction`）。
  投げた瞬間にこの統計が増えるプレイヤーだけを毎tick確認するので、
  投げていないのに反応することがない。
* **レーザー・ロックオン花火の照準（こうもりベースに全面刷新）** — 依頼に
  合わせ、視点方向へ**こうもり（不可視・NoAI）を瞬時にレイキャストで
  100ブロック飛ばす**方式に統一した。レーザーは発射時に1回だけ終点を
  確定して5秒間その位置に固定し（`crossbow/laser/probe_*`）、自分の
  現在地から終点までを毎tick再描画する。ロックオン花火はズーム中
  毎tickこうもりを視点方向へ飛ばし直し、道中のMOBを発光させ続ける
  （`crossbow/zoom/probe_*`）。離した瞬間にこうもりを消し、発光していた
  MOBへ花火を**一直線**に発射する（毎tick追尾はしない）。
* **自動追尾弾のロックオン方式変更** — 以前は「範囲内で一番近いMOB」を
  毎tick選び直していたが、依頼どおり発射時に**視点方向に一番近いMOB**を
  1回だけロックオンし、以後はそのMOBだけを追い続けるように変更した
  （`crossbow/homing/scan_step.mcfunction`）。ダメージも20→80に変更。
* **周囲斬撃の2発目が発動しない不具合** — バニラのMOBには被ダメージ後
  約10tick（0.5秒）の無敵時間があり、同じダメージ量をその間にもう一度
  与えても無効化される。1発目と2発目の間隔が6tickしかなかったため、
  2発目が無敵時間中に着弾し実質何も起きていなかった。間隔を無敵時間より
  長い12tickに変更した（`sword/circle/tick2.mcfunction`）。
* **剣の雨→衝撃波に変更** — Shift+左クリックのアビリティを、上空から
  トライデントを降らせる「剣の雨」から、自分を中心に半径0→18ブロックまで
  0.75秒かけて広がるリング状の「衝撃波」に置き換えた
  （`sword/shockwave/`）。半径ごとに広がるパーティクルの輪と、リングが
  通過した瞬間のMOBへのダメージ判定を、`execute ... distance=$(rmin)..$(rmax)`
  というマクロで動的な半径帯として表現している。
* **飛翔体を見えるようにする** — 自動追尾弾・雪玉3種・ロックオン花火は、
  内部的には完全に不可視の `minecraft:marker` で飛ばしていたため、以前は
  見た目上「何も飛んでいない」状態だった。矢・雪玉・花火それぞれの
  アイコンを表示する `minecraft:item` の実体（発光効果つき）に変更し、
  実際に見える形で飛んでいくようにした。
* **剣のクリック検知（2度目の修正）** — インタラクションエンティティの
  `attack.tick` / `interaction.tick` という細かいNBTパスを直接読んで
  比較する方式は、版によってパスが異なる可能性があり実際に機能して
  いなかった。より確実な「`attack` / `interaction` というタグ自体が
  存在するかどうかだけを見て、見つけたら即座に消費（削除）する」方式に
  変更した（`sword/interact/consume_attack.mcfunction` 等）。
* **ロックオン花火のズーム（2度目の修正）** — クロスボウの発射（=右クリックを
  離した瞬間）を「ズーム開始」の合図にしていたため、切り替え直後の
  1〜2tickでまだ何もしていないのに「離した」と誤判定し、ズームする間も
  なく即座に発射／キャンセルされていた（ロックオン対象への発光だけが
  一瞬見える、という状態になっていた）。スパイグラスに持ち替えた後、
  実際に右クリックを長押しし始めた瞬間（`minecraft:using_item` が最初に
  発火した瞬間）を本当のズーム開始として扱うように変更し、新しくロック
  オンした瞬間には鐘の音とパーティクルの演出を追加した。
* **専用アイテムの判定** — すべて `minecraft:custom_data` に固有のフラグ
  （`uw_crossbow` / `uw_sword` / `uw_snow_blackhole` 等）を付けて判定している。
  同じ見た目のアイテムでも、このフラグが無ければ一切反応しない。
* **クロスボウのエンチャント** — `give` コマンドの `minecraft:enchantments={levels:{...}}`
  という書き方は、このリポジトリの過去の検証（spiderweb パック開発時）で
  実際にゲームから拒否されることが確認されている。そのため本パックでは
  `loot_table` の `minecraft:set_enchantments` 関数を使い、`/loot give` 経由で
  クイックチャージV・無限を安定して付与している（`give_crossbow.mcfunction`）。
* **クロスボウの発射検知** — 当初は `execute on owner` で「矢の持ち主が
  専用アイテムを構えていたか」を判定していたが、実機で反応しない不具合が
  確認されたため、モード切替と同じ「専用アイテムを持っているプレイヤー
  自身を毎tick直接確認し、自分の近く（4ブロック以内）に未処理の矢が
  出現していないか調べる」方式に変更した（`crossbow/check_fire.mcfunction`）。
  見つけた矢は即座にキルし、代わりに自作の弾（自動追尾弾・レーザー用
  こうもり・ロックオン花火用こうもり）を飛ばす。
  * この方式の副作用として、専用アイテムを持ったまま「他人が撃った矢」や
    「地面に落ちている未処理の矢」に4ブロック以内まで近づくと、誤って
    自分が発射したものとして扱われることがごく稀にある（対象が少ない
    通常プレイでは基本的に問題にならない）。雪玉は投擲統計ベースの検知に
    切り替えたため、この副作用は無い。
* **剣のクリック検知エンティティの位置** — 当初 `anchored eyes positioned ~ ~-0.6 ~`
  と書いており、`~`が現在位置（＝足元）からの相対座標だったため、実際には
  視点ではなく足元の下に検知エンティティが出現し、クリックを一切拾えて
  いなかった。`^`（視線方向基準の相対座標）に修正済み。
* **ロックオン花火のズーム演出** — バニラのズーム（視野角の拡大）はスパイグラス
  という特定のアイテムにのみ働くクライアント側の演出のため、クロスボウを
  一時的に本物のスパイグラス（`loot_table/give/aim_spyglass.json`）に入れ替える
  ことで実現している。離す（`minecraft:using_item` アドバンスメントの発火が
  途切れる）と自動的に本物のクロスボウへ戻る。ロックオン対象は
  タグ（`uw.locktgt`）で管理しているため、**複数のプレイヤーが同時にこの
  モードを使うと、ロックオン対象が混線する場合がある**（単独プレイ・少人数
  協力プレイを想定）。
* **剣のクリック検知** — 通常の左クリック（振り攻撃）は、何かに命中しない限り
  サーバー側でほぼ検知できないため、`minecraft:interaction` エンティティを
  プレイヤーの視点位置に常駐させ、その `attack` / `interaction` フィールドの
  変化で左右クリックを検知している（`sword/interact/`）。この方式は
  クロスボウの発射（構える動作）と衝突することがこのリポジトリの過去の
  検証で確認されているため、**最強のダイヤの剣を持っている間だけ**インタラクション
  エンティティを配置し、持ち替えたら即座に片付けるようにしている。
  なお、この仕組みの都合上、剣を持っている間は他のMOB・ブロックへの通常の
  右クリック操作（チェストを開く等）が行えなくなる。
* **飛行モード** — バニラのコマンドには「クリエイティブ飛行を許可する」機能が
  無いため（`/data modify entity` はプレイヤーへの適用が禁止されている）、
  スローフォール（常時）とレビテーション（上を見た時だけ微量に付与）を
  組み合わせた擬似的な飛行で再現している。本物の飛行ほど自由な操作感には
  ならない点に注意。
* **ダメージ量** — 依頼文に数値の指定が無かったアビリティ（レーザー・
  周囲斬撃の半径・衝撃波・ブラックホール・つらら等の一部）は、「最強の武器」
  というコンセプトに沿ってこちらで妥当な値を設定した。上の「調整できる数値」
  の該当ファイルを書き換えれば自由に変更できる。

## ファイル構成

```
ultimateweapon/
├── pack.mcmeta
└── data/
    ├── minecraft/tags/function/   … tick / load への登録
    └── uw/
        ├── predicate/sneaking.json
        ├── advancement/using_item.json   … ズーム中の判定に使用
        ├── loot_table/give/              … クロスボウ・ズーム用スパイグラスの配布
        └── function/
            ├── load / tick / give* / uninstall / help
            ├── crossbow/  … 発射検知・3モード（追尾弾・レーザー・ロックオン花火）
            ├── sword/     … クリック検知・斬撃・周囲斬撃・飛行・衝撃波
            ├── snow/      … 3種類の雪玉（ブラックホール・凍結・つらら）
            └── util/      … 後始末・安全装置
```
